# 题库审校报告（v2.8）

> 19 套题库 184 题，AI 出题 → **人工+代理双维度审校修正** → 校验护栏固化。本报告记录方法、发现与逐卷修正清单。

## 为什么审校

v2.6 题库扩容由 AI 代理按课程原文出题，结构有校验（JSON/module/chapter 锚点）但**内容与效度无人背书**。v2.8 以"最挑剔的评估者"视角审计，抽读两卷即发现硬伤；随后全库审校。

## 审校方法

1. **双维度审**：每题对照 `chapter` 字段指向的课程原文核对**正确性**；以"没读过课程的独立考生"视角检查**效度**（可作答性、干扰项迷惑度、答案可猜度）。
2. **并行分工**：四路并行审校（三路子代理 + 一路人工亲审），改后必须过 `scripts/validate-quizzes.js`。
3. **护栏固化**：把审校发现的可机检规律写进校验器（见下），同类问题从"人记得查"变成"机器必拦"。

## 发现的系统性问题（修正前）

| 问题 | 严重度 | 波及范围 |
|---|---|---|
| 正确答案索引失衡 | **致命** | 7 套卷（security/kubernetes/terraform/ai-job 连点同一选项即可 100 分；ansible/networking/repair-basics 仅 2 个索引） |
| 正确项显著最长 | 高 | 85 处——"选最长的"策略可大面积猜中 |
| 笑话型干扰项 | 中 | "DMZ 只放跳板机""让 CPU 跑得更快"等秒排除项 |
| 课程回指式题干 | 中 | "课程强调的 XX 是什么"——没读过讲义无法作答，测验失去独立效度 |
| 经验数字当确定事实 | 中 | "Spot 便宜 90%""IOPS 贵 10 倍"缺"约/随供需波动"限定 |
| 个别事实瑕疵 | 低 | RDS 责任分界表述、复合捆绑答案（"A 和 C 都对"型） |

## 新增校验护栏（scripts/validate-quizzes.js）

- **索引分布（error 级）**：≥6 道选择题的卷，不同 correct 索引 <3 个直接 fail——"连点同一选项刷分"永不再上线。
- **长度偏向（warning 级）**：正确项 >17 字且 >干扰项均值 ×1.7 告警——"选最长"可猜性提示。
