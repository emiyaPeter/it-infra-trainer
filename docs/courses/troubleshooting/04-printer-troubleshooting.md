## 场景一：打印机无法打印（脱机）

### 最常见的 5 个原因（按频率排序）

```
🔝 1. 打印机电源没开 / USB线松了
🔝 2. Windows 打印机状态设为"脱机使用打印机"
🔝 3. 打印队列中有卡住的任务
🔝 4. 打印机驱动问题
🔝 5. Print Spooler 服务异常
```

### 完整排查流程

```
用户说：点了打印没反应
        │
        ▼
┌─ 第1步：物理检查 ──────────────────────────┐
│  打印机电源灯亮吗？                           │
│  USB/网线插好了吗？                           │
│  液晶屏有报错信息吗？（卡纸/缺墨/缺纸）        │
│  ⚠️ 很多时候只是开机键没按……                  │
└────────────────┬───────────────────────────┘
                 │ 物理正常
                 ▼
┌─ 第2步：检查打印机状态 ──────────────────────┐
│  设置 → 蓝牙和其他设备 → 打印机和扫描仪       │
│  找到对应打印机 → 查看状态                    │
│  "脱机"→ 取消勾选"脱机使用打印机"              │
│  "暂停"→ 取消勾选"暂停打印"                   │
└────────────────┬───────────────────────────┘
                 │ 状态正常
                 ▼
┌─ 第3步：清空打印队列 ────────────────────────┐
│  设置 → 打印机 → 打开打印队列                 │
│  取消所有文档                                 │
│  如果有文档删不掉 → 重启 Print Spooler 服务    │
└────────────────┬───────────────────────────┘
                 │ 队列清空
                 ▼
┌─ 第4步：测试页打印 ─────────────────────────┐
│  右键打印机 → 打印机属性 → 打印测试页         │
│  测试页能打出来吗？                           │
└──────────────────────────────────────────────┘
```

### 重启 Print Spooler 服务（最常用的操作！）

```powershell
# 方法一：命令行（推荐，速度快）
net stop spooler
net start spooler

# 方法二：彻底重置（清空队列 + 重启服务）
net stop spooler
del /f /s /q C:\Windows\System32\spool\PRINTERS\*
net start spooler

# 方法三：服务管理器
services.msc → 找到 Print Spooler → 右键 → 重新启动
```

**这招能解决 50% 以上的打印问题！** 遇到打印机问题先试这招。

## 场景二：打印队列卡住

### 症状

```
- 点了打印没反应
- 打印队列里有一个文档显示"正在打印"但进度永远是 0%
- 取消文档后永远是"正在删除"
- 后面的文档都在排队等待，但都不打印
```

### 完整清理流程

```powershell
# 步骤1：停止打印服务
net stop spooler

# 步骤2：删除卡住的打印任务文件
# 打印队列文件存放位置（每个打印任务一个 .SHD + .SPL 文件）
del /f /s /q C:\Windows\System32\spool\PRINTERS\*

# 步骤3：如果打印机是共享的，也清理注册表中的旧作业
# (通常不需要，但顽固问题可以尝试)
# 位置：HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\Print\Printers\打印机名\Jobs

# 步骤4：重新启动服务
net start spooler

# 步骤5：如果还不行，重启电脑
# Print Spooler 有时会和某些驱动有依赖关系导致无法完全重置
```

## 场景三：打印机显示"脱机"

### 为什么打印机会脱机？

```
常见原因：
1. 误操作：用户不小心点了"脱机使用打印机"（菜单里的选项）
2. 网络断开：网络打印机和电脑之间的连接中断
3. USB 松动：USB 打印机连接不稳定
4. SNMP 误判：Windows 通过 SNMP 查询打印机状态，
   打印机响应超时 → Windows 认为打印机离线
5. 打印机进入了休眠/省电模式
```

### 处理步骤

```powershell
# 1. 取消"脱机使用打印机"
设置 → 蓝牙和设备 → 打印机和扫描仪
→ 选择打印机 → 打开打印队列
→ 打印机菜单 → 取消勾选"脱机使用打印机"

# 2. 对网络打印机：检查是否能 ping 通
ping 打印机IP地址

# 3. 对网络打印机：禁用 SNMP 状态检测（防止 Windows 误判）
# 右键打印机 → 打印机属性 → 端口 → 配置端口
# → 取消勾选"启用了 SNMP 状态"
# → 确定 → 应用
# 
# ⚠️ 这样做后 Windows 不会再自动检测打印机是否在线
#    打印机将始终显示"就绪"

# 4. USB 打印机：
#    换一个 USB 口 → 重新识别
#    换一根 USB 线（USB 线损坏非常常见！）
```

## 场景四：打印机卡纸

### 卡纸取出指南

```
⚠️ 安全第一：
1. 先关机/拔电源！
2. 定影器区域温度极高（激光打印机）→ 等冷却后再操作！
3. 不要用金属工具掏纸 → 可能划伤感光鼓

取出方法：
┌─────────────────────────────────────────┐
│ ① 找到卡纸位置：                          │
│    打开所有能打开的盖子                    │
│    看纸张卡在哪里（进纸口/中间/出纸口）      │
│                                          │
│ ② 顺着纸张方向均匀用力拉出：               │
│    ✅ 双手均匀用力                         │
│    ✅ 顺着进纸方向拉                       │
│    ❌ 不要单边用力（容易撕破）              │
│    ❌ 不要逆着进纸方向拉                   │
│                                          │
│ ③ 如果纸张撕破，碎片留在机器内：            │
│    检查所有辊轴间隙                         │
│    务必把全部碎片取出来                     │
│    残留碎片 = 下一秒又卡纸                  │
│                                          │
│ ④ 取出后检查辊轴上是否有胶水/标签残留       │
└─────────────────────────────────────────┘
```

### 频繁卡纸的原因

```
打印机频繁卡纸，不是"运气不好" — 一定有原因：

1. 纸张问题（最常见！）：
   - 纸张太潮 → 受潮纸容易卷曲粘连
   - 纸张质量太差 → 纸张表面掉屑粘在辊轴上
   - 纸张放歪了
   - 纸盘装太满

2. 搓纸轮/进纸轮磨损：
   - 表面橡胶磨光滑了 → 抓不住纸 → 打滑
   - 用酒精擦拭搓纸轮可以恢复抓力（临时方案）
   - 严重磨损需更换

3. 纸路中有异物：
   - 回形针、订书钉掉进去了
   - 之前卡纸的碎片没清理干净

4. 定影器问题（激光打印机）：
   - 定影膜磨损或积碳 → 纸张粘在上面
```

## 场景五：打印质量异常

### 激光打印机输出质量问题

| 现象 | 可能原因 | 处理 |
|------|---------|------|
| 整页有竖线/竖条 | 感光鼓划伤 | 更换硒鼓 |
| 打印很淡/看不清 | 碳粉不足/感光鼓老化 | 摇晃硒鼓(临时)/更换 |
| 有规律的黑点 | 感光鼓有针孔 | 更换硒鼓 |
| 纸张有底灰 | 废粉仓满了/感光鼓老化 | 清理废粉/换硒鼓 |
| 定影不牢、一擦就掉 | 定影温度不够/定影膜问题 | 检查定影组件 |
| 纸张褶皱/卷曲 | 定影器温度过高或纸张潮 | 换纸/调整纸张类型 |
| 有重影 | 定影器清洁不彻底 | 清理定影器 |

### 喷墨打印机输出质量问题

| 现象 | 可能原因 | 处理 |
|------|---------|------|
| 有横条纹/白线 | 喷头部分堵塞 | 运行喷头清洗 |
| 颜色偏色严重 | 某个颜色墨水没了/喷头堵了 | 检查墨量/清洗喷头 |
| 墨水晕染/扩散 | 纸张不兼容(普通纸上打照片质量) | 换专用纸 |
| 完全打不出某色 | 该墨盒空了或喷头严重堵塞 | 换墨盒/清洗 |
| 喷头堵了 | 长时间不用导致墨水干结 | 用打印机自带清洗功能 |

### 喷墨打印机喷头清洗

```
⚠️ 喷墨打印机长期不用，喷头容易堵塞

打印机自带清洗（首选）：
- 打印机液晶面板 → 维护 → 喷头清洗
- 或 Windows 中：打印机属性 → 维护 → 打印头清洗
- 通常清洗 1-3 次能恢复，不建议连续清洗太多（浪费墨水）

预防措施：
✅ 每周至少打印一次（哪怕只是黑白测试页）
✅ 不用时保持打印机通电（部分打印机有自动维护功能）
✅ 使用原装墨盒（兼容墨盒的墨水更容易干结）
❌ 不要长期断电存放
```

## 场景六：共享打印机连接问题

### 共享打印机的常见场景

```
办公场景：
  打印机 USB 连接在一台电脑上
  → 这台电脑"共享"打印机
  → 其他电脑通过网络连接这台共享打印机

痛点：
  - 主机电脑关机后别人都用不了
  - 主机电脑重装系统后要重新共享
  - Windows 更新经常破坏共享设置
  - 权限设置复杂、容易出错
```

### 共享打印机连接失败排查

```
症状：访问 \\主机名 或共享打印机时提示：
- "Windows 无法连接到打印机"
- "操作失败，错误 0x0000011b"
- "拒绝访问"
- "找不到网络路径"

排查步骤：

1. 主机端检查：
   □ 主机电脑是否开机？
   □ 网络发现和文件共享是否开启？
      控制面板 → 网络和共享中心 → 更改高级共享设置
      → 启用网络发现 + 启用文件和打印机共享
   □ 密码保护的共享是否关闭了？（建议关闭，简化连接）

2. 网络连通性检查：
   ping 主机IP   → 能通吗？
   \\主机IP      → 在资源管理器地址栏输入，能访问共享吗？

3. 常见错误 0x0000011b 修复：
   这是 Windows 更新引入的安全补丁导致的兼容性问题
   
   在主机上以管理员运行：
   reg add "HKLM\SYSTEM\CurrentControlSet\Control\Print" /v RpcAuthnLevelPrivacyEnabled /t REG_DWORD /d 0 /f
   # 重启主机后生效

4. 终极方案：使用 IP 直连
   \\主机IP\打印机共享名
   而不是用 \\主机名\打印机共享名
   （绕过 NetBIOS 名称解析问题）
```

## 场景七：针式打印机发票/快递单打印异常

```
针式打印机在企业中常用于打印多联票据

常见问题：
1. 打印位置不对（偏左/偏右/偏上/偏下）
   → 调整纸张导轨（物理调整）
   → 打印机属性 → 首选项 → 调整纸张大小和边距
   → 部分软件（如金蝶/用友）有自己的打印模板，在软件里调

2. 打印力度不够（下面的联看不清）
   → 调整打印头间隙（打印机上通常有拨杆选择纸张厚度）
   → 多联纸选 3-4 挡

3. 色带干了/断了
   → 更换色带（一般 3-6 个月换一次）

4. 打印出乱码
   → 检查驱动是否正确（针打有专用驱动，不要用通用驱动）
   → 查看数据线是否接触良好
```

## 打印机排障命令速查

```powershell
# 重启打印服务（最常用！）
net stop spooler && net start spooler

# 查看打印机列表
wmic printer get name,printerstatus,workoffline

# 查看打印服务状态
sc query spooler

# 删除某台打印机
# 1. 先打开打印队列窗口，取消所有文档

Get-PrinterDriver | Format-List Name

# 设置默认打印机
# 设置 → 蓝牙和设备 → 打印机 → 选择 → 设为默认值
```

## 实战案例

### 案例1：点了打印后打印机完全没反应

```
场景：用户说打印了很多次，打印机完全不响应

排查：
1. 检查打印机 → 电源灯不亮 → 电源线松了！
   （用户清理工位时碰到了电源线）
2. 插紧电源线 → 打印机正常
3. 打印队列里有积压的 15 个文档 → 清空队列
4. 重新打印 → 正常

教训：永远从最简单的原因开始排查（通电了吗？）
```

### 案例2：网络打印机时好时坏

```
场景：办公室的网络打印机，有时能打、有时不行

排查：
1. 持续 ping 打印机 IP → 发现有时 ping 不通
2. 检查打印机网络设置 → IP 地址是 DHCP 自动获取
3. 查看路由器 DHCP 日志 → IP 租约过期后被其他设备抢走

处理：
在打印机面板上设置静态 IP（如 192.168.1.250）
或在路由器上为打印机 MAC 地址做 DHCP 地址预留

结论：打印机必须有固定 IP！DHCP 自动获取是给自己找麻烦
```

## 自测题

1. 打印机脱机最常见的原因有哪些？（至少说 3 个）
2. `net stop spooler` 命令的作用是什么？为什么它这么重要？
3. 喷墨打印机长期不用会出现什么问题？如何预防？
4. 激光打印机打印出来的字一擦就掉，是什么问题？
5. 同一台网络打印机，一半的人能打、一半的人不能打，问题可能在哪里？

<details>
<summary>点击查看答案</summary>

1. **最常见原因**：① 用户误点击了"脱机使用打印机"；② USB/网线松动或电源没开；③ 打印队列中有卡住的文档；④ Print Spooler 服务异常；⑤ SNMP 检测导致 Windows 误判打印机离线
2. **`net stop spooler` 停止打印后台处理服务**。该服务管理所有打印作业队列。卡住的打印作业实际上是被锁在内存中，重启服务会释放这些资源。配合删除 `spool\PRINTERS\*` 文件，是解决打印队列卡住问题的"万能钥匙"。能解决 50%+ 的打印问题
3. **喷头堵塞**。墨水在喷头中干结，导致无法正常喷墨。预防：每周至少打印一次（哪怕测试页）、打印机保持通电状态、使用原装墨盒（兼容墨盒更容易干）。如果已堵塞，运行打印机自带的喷头清洗功能
4. **定影问题**。激光打印机的定影器通过高温高压将碳粉熔固在纸张上。如果定影温度不够（定影灯老化/定影膜破损），碳粉就无法牢固附着。需要维修或更换定影组件。另外纸张类型设置错误（设置了厚纸但实际用普通纸）也可能导致
5. **排查方向**：① 检查那些人是否连到同一台打印机（可能有多台同名打印机）；② 检查他们的电脑和打印机是否在同一子网（VLAN 隔离）；③ 检查打印机端口配置（有些用了 WSD 端口、有些用 TCP/IP）；④ 检查 IP 地址（打印机 IP 变了，有些人用的还是老 IP）；⑤ 检查驱动版本差异
</details>
