## 排障核心方法论

```
┌─────────────────────────────────────────────────────────┐
│                   🎯 OSI 排障法（自下而上）                │
│                                                         │
│  第1层 物理层：网线插好了吗？灯亮吗？                      │
│    ↓ 正常                                               │
│  第2层 链路层：能获取到 IP 吗？MAC 地址对吗？              │
│    ↓ 正常                                               │
│  第3层 网络层：能 ping 通网关吗？路由对吗？                │
│    ↓ 正常                                               │
│  第4层 传输层：端口通吗？防火墙拦了吗？                    │
│    ↓ 正常                                               │
│  第7层 应用层：DNS 解析正常吗？浏览器/应用设置对吗？        │
│                                                         │
│  ⚡ 技巧：80% 的网络问题在第 1-3 层！                     │
└─────────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────────┐
│              🔄 "二分法" 快速定位问题                      │
│                                                         │
│  把复杂系统一分为二，先确定问题在哪一半：                   │
│                                                         │
│  "所有网站都打不开" vs "只有某个网站打不开"                │
│   → 所有打不开 = 网络/DNS 问题                           │
│   → 某个打不开 = 那个网站的问题                           │
│                                                         │
│  "所有电脑都上不了网" vs "只有我这台上不了"                │
│   → 所有上不了 = 路由器/出口问题                         │
│   → 只有一台 = 那台电脑的问题                             │
└─────────────────────────────────────────────────────────┘
```

## 排障黄金法则

1. **一次只改一个变量** — 改多个设置可能解决了一个问题但引入新问题
2. **改之前记下原值** — 方便回退
3. **先确认症状可复现** — 不能稳定复现的问题最难排查
4. **重启大法是真的有用** — 清除临时状态，释放资源
5. **做好记录** — 排障过程和结果记录下来，未来省时间

## 排障常用命令速查

| 命令 | 用途 | 示例 |
|------|------|------|
| `ping` | 测试网络连通性 | `ping 8.8.8.8` |
| `tracert` | 追踪路由路径 | `tracert baidu.com` |
| `nslookup` | DNS 查询 | `nslookup baidu.com` |
| `ipconfig` | 查看/刷新IP配置 | `ipconfig /all` |
| `netstat` | 查看网络连接和端口 | `netstat -ano` |
| `route print` | 查看路由表 | `route print` |
| `telnet` | 测试端口连通性 | `telnet 10.0.0.1 443` |
| `curl` | HTTP 请求测试 | `curl -v https://baidu.com` |
