# 组策略（GPO）

组策略是 Windows 域的"遥控器"：一次配置，域内成百上千台电脑统一生效。改桌面壁纸、强制锁屏、禁止装软件、下发安全基线——全靠它。

## 1. GPO 的工作模型

```
GPO（策略集合） ──链接──> 站点 / 域 / OU（SOM，作用域）
                          │
客户端启动/登录时 ──拉取──> 生效的 GPO 合并结果
```

三个关键规则：

- **链接位置**：同一个 GPO 可以链接到多个 OU；一个 OU 也可以挂多个 GPO
- **继承**：上级（域）→ 下级（OU）逐层应用，**子级默认继承父级**
- **优先级**：链接顺序编号越小越后应用、优先级越高；子 OU 可勾选 **"阻止继承"**，父 GPO 可勾选 **"强制（Enforced）"** 压过阻止

管理入口：`gpmc.msc`（组策略管理）。

## 2. 实验一：全域密码策略（Default Domain Policy）

密码策略必须在**域级别**的 Default Domain Policy 里配（低于域级别的密码策略对域账号无效——高频坑）。

路径：`gpmc.msc → 域 corp.local → Default Domain Policy → 编辑 → 计算机配置 → 策略 → Windows 设置 → 安全设置 → 账户策略 → 密码策略`

| 设置项 | 建议值 | 说明 |
|--------|--------|------|
| 密码长度最小值 | 12 | 当前主流基线 |
| 密码最短使用期限 | 1 天 | 防止用户把密码改一圈又回到旧密码 |
| 密码最长使用期限 | 90 天 | 部分新基线（NIST）已不强制轮换，企业按制度 |
| 强制密码历史 | 24 个 | 记住历史密码防复用 |
| 账户锁定阈值 | 5 次无效 | 超过即锁定 |
| 账户锁定持续时间 | 15 分钟 | 自动解锁 |

## 3. 实验二：OU 级桌面管控（自定义 GPO）

给"IT部"OU 建一条自定义 GPO：

```powershell
# 命令行创建并链接（等同 GUI 右键新建+链接）
New-GPO -Name "IT部-桌面基线" | New-GPLink -Target "OU=IT部,DC=corp,DC=local"
```

编辑这个 GPO，配两条经典策略（`gpme` 或右键编辑）：

1. **统一壁纸**：用户配置 → 策略 → 管理模板 → 桌面 → 桌面 → Active Desktop 墙纸
2. **禁止运行特定程序**（如任务管理器示例）：用户配置 → 管理模板 → 系统 → "不要运行指定的 Windows 应用程序"

## 4. 让策略生效与排障

```powershell
# 手动刷新（否则要等 90 分钟自动刷新）
gpupdate /force

# 查看本机实际生效的策略及来源（排障核心工具）
gpresult /r            # 摘要：哪些 GPO 应用了、哪些被过滤
gpresult /h report.html  # 完整 HTML 报告
```

**排障思路**（面试常客）：

| 现象 | 排查点 |
|------|--------|
| 策略不生效 | `gpresult /r` 里 GPO 是否列出；是否被"阻止继承"挡掉 |
| 安全策略不生效 | 密码策略必须挂在**域**级；是否误挂 OU |
| 用户策略不生效 | 域用户登录的是**域内机器**吗（本地账户不吃域 GPO 用户策略）|
| 改了不刷新 | `gpupdate /force`；部分策略需重启/重登（目标明确标注） |

::: tip 安全筛选
GPO 默认对"Authenticated Users"生效。若只想对某组生效：GPO 的"安全筛选"里移除 Authenticated Users、添加目标组——但记住同时把"域计算机"加进**委派→读取**，否则计算机侧策略拉取失败（经典深坑）。
:::

## 5. 生产视角

- GPO 数量会失控——建立**命名规范**（如"OU名-用途"）和变更记录
- 改动先在测试 OU 验证再铺开；GPMC 自带"更改日志"
- 微软安全基线（Security Compliance Toolkit）提供成套 GPO 模板，比自己一条条配更稳

## 常见误区

1. **把密码策略挂到 OU**——对域账号永远无效，必须在域级
2. **GPO 当配置文件仓库乱堆**——一年后没人敢动任何一条；宁少而准
3. **忘记 gpupdate 就下结论"策略没用"**——刷新周期默认 90 分钟

## 小结

- GPO 链接到 站点/域/OU，子级继承父级，Enforced > 阻止继承
- 密码策略必须域级；排障三件套：`gpupdate /force` + `gpresult /r` + 安全筛选检查

## 练习

1. 配置域密码策略后，故意在 CLIENT01 用 3 位密码改密，验证被拒
2. 给"IT部"OU 配壁纸策略，`gpupdate /force` 后注销重登验证
3. 在"IT部"OU 上开"阻止继承"，用 `gpresult /r` 观察域级策略消失，再关掉恢复
