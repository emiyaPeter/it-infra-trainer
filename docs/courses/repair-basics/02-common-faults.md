# 02 - 常见硬件故障与更换

## 故障排查的黄金法则

```
1. 先软后硬 — 先排查软件/驱动/设置，再拆硬件
2. 先外后内 — 先检查外部连接(线缆/接口)，再拆机检查内部
3. 先简后繁 — 先做简单检查(重启/换线/除尘)，再做复杂更换
4. 替换法   — 用确定正常的部件替换可疑部件，是定位问题的最可靠方法
5. 最小系统 — 只保留CPU+主板+1根内存+电源，排除其他部件干扰
```

## 一、电源故障排查

### 症状速查表

| 症状 | 可能原因 | 处理 |
|------|---------|------|
| 按开机键完全无反应 | 电源线松动/电源开关关闭/电源损坏 | 检查线缆→电源开关→短接测试 |
| 开机风扇转一下就停 | 短路保护/电源过载 | 断开所有负载，逐一接入排查 |
| 正常使用中突然重启 | 供电不稳/功率不足 | 计算总功耗，检查电源老化 |
| 开机后闻到焦味 | 元器件烧毁 | **立即断电！** 更换电源 |
| 高负载时死机/蓝屏 | +12V 输出不足 | 测试或更换电源 |

### 实战：更换电源

```
准备工具：十字螺丝刀

步骤：
1. ⚡ 拔掉电源线！拔掉所有连接到主板/硬盘/显卡的供电线
2. 拍照记录每条线的连接位置（非常重要！）
3. 拧下机箱后面板固定电源的 4 颗螺丝
4. 取出旧电源，放入新电源
5. 按拍照记录连接所有供电线：
   - 主板 24pin（最大那个）
   - CPU 8pin（主板左上角，千万别漏！）
   - 显卡 PCIe 供电（6pin/8pin，如有独立显卡）
   - SATA 供电（每个硬盘一根）
6. 整理线缆（用扎带），不挡风扇
7. 插电，按开机键测试
```

### 电源功率估算

| 配置级别 | CPU | GPU | 建议电源 |
|---------|-----|-----|---------|
| 办公机 | i3/R3 | 集成显卡 | 300-400W |
| 入门游戏 | i5/R5 | GTX 1660/RTX 3060 | 500-550W |
| 中端游戏 | i7/R7 | RTX 3070/4070 | 650-750W |
| 高端游戏 | i9/R9 | RTX 4080/4090 | 850-1000W |
| 入门服务器 | Xeon E | - | 400-500W |

**公式**：(CPU TDP + GPU TDP + 150W 余量) × 1.2 = 推荐电源功率

## 二、内存故障详解

### 内存故障的典型蓝屏代码

```
MEMORY_MANAGEMENT (0x0000001A)  → 内存管理错误
PFN_LIST_CORRUPT (0x0000004E)    → 页帧号列表损坏
PAGE_FAULT_IN_NONPAGED_AREA     → 页面文件错误
IRQL_NOT_LESS_OR_EQUAL           → 驱动冲突/内存损坏
BAD_POOL_HEADER                  → 内存池头损坏
```

### 内存排查三步法

#### 第一步：物理检查
```bash
1. 关机、断电
2. 打开机箱，找到内存条
3. 按下内存插槽两端的卡扣，取出内存条
4. 检查金手指：是否有氧化(发黑)、烧毁痕迹
5. 用橡皮擦轻轻擦拭金手指（单向擦，不要来回）
6. 用气吹清理内存插槽
7. 重新插入内存条（听到"咔嗒"两声确认卡到位）
8. 开机测试
```

#### 第二步：单根测试
```
如果有多根内存：
1. 只插一根内存，开机测试 30 分钟
2. 换另一根，同样的插槽，再测
3. 换不同插槽重复测试
→ 定位到哪个插槽或哪根内存有问题
```

#### 第三步：软件检测
```bash
# Windows 自带内存诊断
mdsched.exe
# 选择"立即重新启动并检查问题"

# 或下载 MemTest86 制作启动U盘深度检测
# 检测时长：16GB 内存约 1-2 小时
# Pass 数达到 4 次无错误说明内存基本健康
```

### 实战：更换/加装内存

```
⚠️ 选购注意事项：
1. 确认内存类型(DDR3/DDR4/DDR5) — 查主板说明书或用 CPU-Z
2. 台式机用 DIMM(长条)，笔记本用 SO-DIMM(短条)
3. 频率取主板和CPU支持的最低值（如CPU支持3200，买了3600也能用，但只跑3200）
4. 双通道要买两根同品牌同型号（套装最佳）

安装步骤：
1. 断电，打开机箱
2. 找到内存插槽，掰开两端卡扣
3. 对准缺口方向，均匀用力向下按
4. 听到两端"咔嗒"声，卡扣自动回位 → 装好了
5. 双通道安装：通常插在相同颜色的插槽上（如第2和第4槽，看主板说明书）
```

## 三、硬盘故障与数据安全

### 硬盘故障的预警信号 🚨

```
机械硬盘 (HDD)：
⚠️ 硬盘发出"咔嗒咔嗒"异响 → 磁头可能损坏，立即备份！
⚠️ 读取文件时异常缓慢、经常卡顿
⚠️ 文件突然无法打开、提示损坏
⚠️ SMART 05/C5/C6 指标非零

固态硬盘 (SSD)：
⚠️ 写入速度突然大幅下降
⚠️ 文件变成只读、无法写入
⚠️ 系统频繁蓝屏，错误指向存储
⚠️ SSD 识别不到、掉盘
```

### 实战：更换 M.2 NVMe SSD

```
准备工具：小号十字螺丝刀（通常 M2×3mm 螺丝）

1. 关机、断电
2. 找到主板上的 M.2 插槽（通常靠近 CPU 或在 PCIe 插槽之间）
3. 如果原有 SSD 有散热片，先拧下散热片螺丝
4. 拧下固定 SSD 的小螺丝
5. M.2 SSD 会弹起约 30°，轻轻拔出
6. 新 SSD 以约 30° 插入 → 按平 → 拧上固定螺丝
7. 如需散热片，撕掉导热垫保护膜，装上散热片
8. 装好系统后安装 CrystalDiskInfo 验证健康状态
```

### 数据恢复优先级

```
硬盘出问题时的操作优先级：
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第1优先：立即备份最重要的数据！
第2优先：备份其余数据
第3优先：再检查/修复硬盘
第4优先：考虑更换硬盘

❌ 千万不要：
  - 强行 chkdsk /f 修复坏道（可能加重损坏）
  - 继续写入新数据（可能覆盖可恢复的数据）
  - 反复重启看能不能"好起来"
  - 拆开硬盘外壳（普通环境灰尘直接毁掉盘片）
```

## 四、散热问题排查

### CPU 温度异常排查流程

```
CPU 待机温度 > 50°C 或 满载 > 90°C
        │
        ▼
   检查散热风扇是否转动？
    ┌─── 否 → 检查风扇电源线是否插好 → 更换风扇
    │
    ▼ 是
   风扇转速是否正常(>800RPM)?
    ┌─── 否 → 清理灰尘/更换风扇
    │
    ▼ 是
   散热器是否安装牢固？
    ┌─── 否 → 重新安装（注意对角均匀拧紧）
    │
    ▼ 是
   硅脂是否干了(超过2年未更换)？
    ┌─── 是 → 清理旧硅脂 → 涂抹新硅脂
    │
    ▼ 是
   机箱风道是否堵塞？
    ┌─── 是 → 清理进出风口 → 整理线缆
    │
    ▼ 是
   检查 BIOS 中风扇曲线设置
```

### 实战：更换 CPU 硅脂

```
准备工具：硅脂、酒精棉片(或 90%+ 酒精 + 无尘布)、螺丝刀

1. 电脑断电，拆下 CPU 散热器
2. 用酒精棉片擦干净 CPU 顶盖和散热器底部的旧硅脂
   → 擦到反光、看不到残留为止
3. 在 CPU 顶盖中央挤出绿豆大小的硅脂（约 3-5mm 直径）
   （笔记本裸 Die 芯片用"米粒大小"即可）
4. 装上散热器，对角均匀拧紧螺丝
   → 不要拧太紧！手指感到阻力后，再拧 1/4 圈即可
5. 装好后开机，进系统用 HWiNFO 验证温度
6. 刚装好温度可能偏高，硅脂需要 1-2 天"磨合"到最佳效果
```

### 硅脂涂抹方法对比

```
❌ 用手指抹平  → 容易有气泡
❌ 涂太多      → 溢出到主板，有短路风险
✅ 中间一点法  → 散热器压下后自然均匀铺开（推荐）
✅ 画X法       → 适用于较大的CPU顶盖（如 Intel LGA1700）
✅ 五点法      → 四角 + 中心各一点，适合 Threadripper 等大顶盖CPU
```

## 五、经典故障案例

### 案例1：开机无显示，风扇正常转

```
场景：用户说"电脑开机黑屏，但风扇在转"

排查过程：
1. 检查显示器是否打开、信号线是否插对（插到显卡不是主板）
   → 显示器正常，线插对了

2. 听有没有蜂鸣器报警声
   → 有！连续长响（内存错误）

3. 关机断电，重新插拔内存
   → 开机成功！

结论：内存接触不良（可能是搬运震动导致）
```

### 案例2：电脑随机重启

```
场景：用户反映"用着用着就突然重启，没有蓝屏"

排查过程：
1. 检查 Windows 事件查看器 → 发现 Kernel-Power 41 错误
2. 用 HWiNFO 查看温度和电压
   → CPU 温度正常，但 +12V 电压在 11.2V-11.6V 波动（正常 ±5% 即 11.4-12.6V）

3. 替换电源后测试
   → 问题消失

结论：电源老化，+12V 输出不稳定
```

### 案例3：电脑越来越慢，最后卡死

```
场景：老电脑，开机后能用几分钟，然后越来越慢直到卡死

排查过程：
1. 任务管理器 → CPU 使用率 100%，但所有进程都显示很低
2. 资源监视器 → CPU 频率只有 0.8 GHz（正常应该 2.5+ GHz）
3. HWiNFO → CPU 温度 98°C！（过热降频保护）

4. 拆机检查 → 散热器被灰尘完全堵死
5. 清理灰尘 + 更换硅脂
   → 恢复正常

结论：散热器严重积灰导致 CPU 过热降频
```

## 自测题

1. 按开机键完全没反应，排查顺序是什么？
2. 硬盘发出"咔嗒"声意味着什么？应该怎么做？
3. 如何判断是内存坏了还是内存插槽坏了？
4. CPU 待机 60°C 正常吗？应该检查什么？
5. 更换 M.2 SSD 需要注意什么？

<details>
<summary>点击查看答案</summary>

1. **排查顺序**：电源线是否插紧 → 电源后面开关是否打开 → 排插是否通电 → 主板 24pin 和 CPU 8pin 是否插紧 → 短接测试电源是否工作 → 检查机箱开机按钮是否损坏（可用螺丝刀短接主板 Power SW 针脚测试）
2. **"咔嗒"声 = 磁头反复尝试读取失败，是机械硬盘即将彻底损坏的明确信号。立即备份数据！不要再尝试正常使用，每次通电都可能造成更多损坏**
3. **替换法**：把内存换到另一个插槽测试。如果换插槽后内存正常 → 原插槽有问题；如果内存在任何插槽都有问题 → 内存本身有问题
4. **偏高但不一定有问题**。首先确认环境温度、检查散热风扇是否正常转动、看硅脂是否干了。如果笔记本待机 60°C，可能在正常范围（笔记本散热差）。台式机待机 60°C 偏高，应该清理灰尘和更换硅脂
5. **注意事项**：确认插槽类型(PCIe Gen3/Gen4/Gen5)、检查是否与 SATA 端口冲突（部分主板 M.2 会禁用某个 SATA 口）、小心螺丝很小容易丢、安装角度约 30° 斜插再按平、有散热片的话记得撕导热垫保护膜
</details>
