# 电脑维修基础

> 🎯 **目标**：能够独立诊断常见电脑故障，掌握硬件更换和系统修复的基本技能  
> ⏱ **建议时长**：2-4 周（每天 1-2 小时）  
> 📊 **难度**：⭐ 入门  

## 为什么 IT 工程师需要懂硬件维修？

作为 IT 基础设施工程师，你日常工作中会遇到大量硬件相关问题：

- 🖥️ **用户电脑无法开机** — 需要快速判断是电源、主板还是其他部件故障
- 💾 **硬盘故障预警** — 在数据丢失前发现并更换故障硬盘
- 🖨️ **外设无法识别** — 打印机、扫描仪等外设的连接问题
- 🔧 **内存/硬盘升级** — 为公司电脑升级硬件配置

**省钱 + 高效 = 核心竞争力**。企业 IT 支持中，70% 的问题可以通过基础硬件排查解决，无需送修。

## 学习建议

1. **找一台旧电脑练手** — 拆开再装回去，是最好的学习方式
2. **安全第一** — 操作前务必断电！拔掉电源线后再操作
3. **拍照记录** — 拆机前拍下各个角度的照片，方便还原
4. **防静电** — 接触电子元件前先摸金属物体释放静电
5. **备一个小螺丝刀套装** — 十字、一字、梅花批头都备齐

## 安全须知 ⚠️

```
⚡ 高危操作（务必断电）：
  - 电源拆卸/更换 → 即使断电，电源内电容仍可能存有高压电！
  - 主板插拔 → 关机、断电、按开机键释放残余电荷
  - 硬盘拆卸 → 机械硬盘运行中移动可能损坏磁头

🔰 安全操作：
  - 戴防静电手环或先摸金属接地物体
  - 保持工作台整洁干燥
  - 拆卸的螺丝分类放置（可用磁吸垫或小盒子）
  - 不确定的线缆先拍照再拔
```
