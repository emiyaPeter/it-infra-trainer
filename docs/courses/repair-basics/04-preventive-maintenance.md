# 04 - 预防性维护与保养

> 💡 **核心理念**：预防比维修更省钱。一台定期保养的电脑能用 5-8 年，不做保养可能 2-3 年就出问题。

## 维护周期建议

| 维护项目 | 频率 | 适用场景 |
|---------|------|---------|
| 清理机箱灰尘 | 3-6 个月 | 所有电脑 |
| 更换 CPU 硅脂 | 1-2 年 | 所有电脑 |
| 检查硬盘健康状态 | 1 个月 | 有重要数据的电脑 |
| 清理系统垃圾文件 | 1 个月 | Windows 系统 |
| 检查散热风扇运转 | 3 个月 | 所有电脑 |
| 整机线缆整理 | 1 年 | 台式机 |
| 备份重要数据 | 每周/每月 | 所有设备 |
| 更新驱动程序 | 按需（有安全更新时）| 所有电脑 |

## 一、清灰保养

### 灰尘的危害

```
灰尘 = 电脑的慢性杀手
├── 堵塞散热片 → 散热效率下降 → 温度升高
├── 包裹风扇轴承 → 风扇转速下降或停转
├── 积累在电路板上 → 受潮后可能导致短路
├── 堵住机箱进出风口 → 空气流通受阻
└── 进入内存/显卡插槽 → 接触不良
```

### 清灰步骤

```
准备工具：
- 压缩空气罐 或 电动吹风机（冷风模式）
- 软毛刷（油漆刷即可）
- 防尘口罩
- 螺丝刀套装

⚠️ 清灰环境：室外或通风良好的阳台！室内清灰会让灰尘四处飞扬

步骤：
1. 关机、断电、拔掉所有线缆
2. 打开机箱侧板
3. 用压缩空气罐（保持 10-15cm 距离）：
   a. 先吹电源出风口（从机箱外面往里吹）
   b. 再吹 CPU 散热器翅片（从散热片缝隙方向吹）
   c. 吹显卡散热器
   d. 吹机箱风扇
   e. 吹主板表面
   f. 最后吹机箱底部（灰尘最多的地方）

4. 顽固灰尘：用软毛刷轻轻刷松，再吹
5. 风扇叶片的顽固灰尘：用棉签+少量酒精擦拭

⚠️ 注意事项：
  - 压缩空气罐不要倒置使用（会喷出液体）
  - 吹风扇时用手指轻轻按住扇叶，防止高速旋转损坏轴承
  - 不要用吸尘器（会产生静电！）
  - 不要用湿布擦拭电路板
```

## 二、硅脂更换

### 什么是硅脂？为什么要换？

```
CPU/GPU 表面和散热器底面看似光滑，实际上微观层面有很多凹坑。
硅脂填充这些凹坑，确保热量有效传递。

硅脂随时间变化：
新的 → 湿润、导热好 → 6个月后开始变干 → 1-2年后干裂、导热下降
                                    ↓
                            CPU 温度可能上升 10-20°C！
```

### 硅脂更换全流程

```
准备：
- 优质硅脂（推荐：信越 7921、Arctic MX-4/MX-6、猫头鹰 NT-H2）
- 90%+ 浓度酒精 + 无尘布（或用酒精棉片）
- 螺丝刀

步骤：
1. 开机运行 10 分钟让硅脂软化（方便拆卸）
2. 关机、断电
3. 拧下 CPU 散热器螺丝 / 松开卡扣
4. 轻轻旋转散热器（左右转动）再取下（不要硬拔！）
5. 用酒精棉片擦净 CPU 顶盖和散热器底面的旧硅脂
   → 擦到反光，看不到黑色残留为止
6. 在 CPU 顶盖中心挤出绿豆大硅脂（约 3-5mm）
7. 装回散热器，对角均匀拧紧
8. 开机验证温度

笔记本注意事项：
- CPU/GPU 为裸 Die（没有金属顶盖！），硅脂用米粒大小即可
- 拆机顺序更复杂，先搜"你的笔记本型号 + 拆机教程"
- 有些笔记本使用液态金属散热（如高端游戏本），不要自己更换！
```

## 三、线缆管理

### 为什么要整理线缆？

```
杂乱线缆 ≠ 只影响美观

实际影响：
├── 阻碍机箱风道 → 散热变差 → 温度升高 3-8°C
├── 触碰风扇叶片 → 噪音 + 风扇损坏
├── 增加灰尘附着面积
├── 下次维护时误拔/误碰
└── 老鼠/蟑螂的"攀爬架"（真的！）
```

### 理线技巧

```
1. 利用机箱背板走线空间
   - 电源线尽量从背板走
   - 前面只留必须的线

2. 使用扎带分组绑扎
   - 按线缆类型分组（供电/数据/面板线）
   - 不要绑太紧，留一点活动空间
   - 可用魔术贴扎带替代一次性扎带（便于后续维护）

3. SATA 线走直角弯
   - SATA 线不要过度弯折
   - 弯曲半径不小于 2cm

4. 前面板线整理
   - 用扎带绑在一起沿机箱边缘走
   - 避免悬在主板上方
```

## 四、系统日常维护

### Windows 系统清理

```powershell
# 1. 磁盘清理（系统自带）
cleanmgr
# 选择 C 盘 → 勾选"Windows更新清理"等 → 确定

# 2. 删除临时文件
# 设置 → 系统 → 存储 → 临时文件 → 删除

# 3. 清理软件分发文件夹（Windows更新缓存）
net stop wuauserv
del /f /s /q C:\Windows\SoftwareDistribution\Download\*
net start wuauserv

# 4. 检查磁盘健康
wmic diskdrive get status

# 5. 整理磁盘碎片（仅 HDD！SSD 不要做！）
defrag C: /U /V
```

### ⚠️ SSD 千万不要碎片整理！

```
碎片整理(Defrag)是针对机械硬盘的优化 —— 把分散的数据搬到一起。
SSD 工作原理不同，碎片整理会导致大量不必要的写入，缩短寿命！

Windows 10/11 会自动识别 SSD 并执行 TRIM（而非碎片整理），
不需要手动操作。
```

### 定期检查清单

```
月度检查：
□ 备份重要文件到外置硬盘或云盘
□ 检查 C 盘剩余空间（保持 20%+ 空闲）
□ 用 CrystalDiskInfo 快速查看硬盘健康
□ Windows Update 安装安全更新
□ 检查杀毒软件是否正常运行

季度检查：
□ 清理机箱灰尘
□ 查看事件查看器中有无异常错误
□ 清理不需要的软件（控制面板→程序和功能）
□ 导出浏览器书签备份

年度维护：
□ 更换 CPU 硅脂
□ 检查所有风扇运转情况
□ 检查电容是否有鼓包
□ 重新整理线缆
□ 清理外设（键盘、鼠标）
□ 评估是否需要硬件升级
```

## 五、外设维护

### 键盘清洁

```
机械键盘：
1. 拔掉 USB 线
2. 用拔键器取下所有键帽
3. 键帽放温水中 + 少量洗洁精浸泡 30 分钟
4. 用小刷子 + 压缩空气清理轴体之间的灰尘碎屑
5. 键帽晾干后装回

普通键盘：
- 压缩空气吹缝隙
- 湿布（微湿！）擦拭表面
- 倒过来拍几下，碎屑会掉出来
```

### 显示器清洁

```
⚠️ 不要用玻璃清洁剂！会损坏屏幕涂层！
⚠️ 不要用纸巾！会留下划痕！

正确方法：
1. 关闭显示器（黑屏时更容易看到污渍）
2. 用超细纤维布（眼镜布即可）轻轻擦拭
3. 顽固污渍：微纤维布沾少量清水（拧干！）擦拭
4. 擦干：用干微纤维布擦干，避免水渍
```

### 打印机维护（基础）

```
激光打印机：
- 定期清理内部碳粉（用专用碳粉吸尘器或压缩空气）
- 检查定影器是否有残留碳粉
- 进纸轮用酒精清洁防打滑

喷墨打印机：
- 长期不用时，每周至少打印一次（防止喷头堵塞）
- 喷头堵塞 → 运行打印机自带的"喷头清洗"功能
- 使用原装墨盒（兼容墨盒更容易堵喷头）
```

## 六、数据备份策略

### 3-2-1 备份法则（企业标准）

```
3 — 至少 3 份数据副本（1份原件 + 2份备份）
2 — 使用 2 种不同存储介质（如：本地硬盘 + 云存储）
1 — 至少 1 份异地备份（防止火灾/盗窃等物理灾害）

示例：
✅ 电脑里的工作文件（原件）
✅ 移动硬盘每天自动备份（本地备份）
✅ OneDrive/百度网盘 实时同步（云备份 = 异地备份）
```

### 家庭用户简易备份方案

```
推荐工具（均免费）：
- FileHistory（Windows 自带）：自动备份文件版本
- Veeam Agent for Windows（免费版）：整机备份
- FreeFileSync：跨盘/跨网络同步

Windows 自带备份：
设置 → 更新和安全 → 备份 → 添加驱动器（外接硬盘）
→ 打开"自动备份我的文件" → 选择要备份的文件夹
```

## 自测题

1. 电脑应该多久清灰一次？SSD 应该做碎片整理吗？
2. CPU 硅脂建议多久换一次？不换会有什么后果？
3. 3-2-1 备份法则是什么？
4. 清理显示器屏幕时，哪两种东西不能用？
5. 清理风扇时，为什么要按住扇叶？

<details>
<summary>点击查看答案</summary>

1. **3-6 个月清灰一次**（取决于环境尘土情况）。**SSD 千万不要做碎片整理！** Windows 会自动对 SSD 执行 TRIM 优化。碎片整理只适用于 HDD
2. **1-2 年换一次**。不换会导致硅脂干裂、导热性能大幅下降，CPU 待机温度可能从 35°C 升到 55°C+，满载时可能触发温度墙降频，性能严重下降
3. **3 份副本**（1份原件+2份备份）、**2 种不同介质**（如本地硬盘+云盘）、**至少1份异地存储**（防止火灾/盗窃等物理损失）
4. **玻璃清洁剂**（含氨或酒精，会损坏屏幕涂层）和**纸巾/面巾纸**（纤维粗糙，容易留下细微划痕）
5. **防止高速旋转损坏风扇轴承**。压缩空气气流会让扇叶高速旋转，超出设计的转速范围会加速磨损甚至损坏轴承。正确的做法是用手指轻轻按住扇叶再吹
</details>
