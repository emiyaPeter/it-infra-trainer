# 01 - 电脑硬件组成与检测

## 台式机 vs 笔记本：内部结构差异

```
台式机 (Desktop)                          笔记本 (Laptop)
┌─────────────────────────┐              ┌─────────────────┐
│  电源 (PSU)              │              │  电池            │
│  ┌─────────────────┐    │              │  ┌─────────────┐ │
│  │  主板 (Motherboard) │ │              │  │  主板(集成)   │ │
│  │  ├ CPU + 散热器     │ │              │  │  ├ CPU(焊接)  │ │
│  │  ├ 内存插槽 × 2-4  │ │              │  │  ├ 内存(插槽) │ │
│  │  ├ 显卡插槽 (PCIe) │ │              │  │  ├ 硬盘(M.2)  │ │
│  │  ├ 硬盘架 × 2-6   │ │              │  │  └ 散热风扇   │ │
│  │  └ 扩展插槽       │ │              │  └─────────────┘ │
│  └─────────────────┘    │              │  屏幕 (集成)     │
│  机箱风扇               │              └─────────────────┘
└─────────────────────────┘
```

**关键区别**：
- 台式机：部件标准化、可自由更换、散热好
- 笔记本：高度集成、CPU/GPU 通常焊接、升级空间有限（通常只能换内存和硬盘）

## 1. 主板 (Motherboard) — 所有部件的"交通枢纽"

### 主板主要接口识别

```
          I/O面板（USB/网口/音频/显示接口）
┌──────────────────────────────────────────────┐
│  ┌──────────┐                    ┌────────┐  │
│  │ CPU插座   │ ←── 内存插槽 ──→  │ 内存   │  │
│  │ (LGA/PGA) │     (DIMM)       │ DDR4/5 │  │
│  └──────────┘                    └────────┘  │
│       │                                      │
│       ▼ 芯片组 (Chipset)                     │
│  ┌──────────────────────────────────────┐    │
│  │  PCIe x16 (显卡)                      │    │
│  │  PCIe x1  (声卡/网卡等扩展卡)         │    │
│  │  M.2 插槽 (NVMe SSD)                 │    │
│  │  SATA 接口 × 4-6 (硬盘/光驱)         │    │
│  │  USB 前置面板接口                    │    │
│  │  前面板音频接口                       │    │
│  │  电源接口 (24pin + 8pin CPU供电)     │    │
│  └──────────────────────────────────────┘    │
│  电池 (CMOS Battery) — 保存BIOS设置          │
└──────────────────────────────────────────────┘
```

### 主板常见故障
- **不开机**：检查 24pin 电源和 CPU 8pin 供电是否插紧
- **CMOS 电池耗尽**：电脑时间每次开机都重置
- **电容鼓包**：主板上的圆柱形电容顶部鼓起或漏液 → 需更换主板
- **内存插槽氧化**：用橡皮擦擦拭内存金手指

### 检测方法
```powershell
# Windows 中查看主板信息
wmic baseboard get product,manufacturer,version

# 查看 BIOS 版本和日期
wmic bios get smbiosbiosversion,releasedate
```

## 2. CPU (中央处理器) — 电脑的"大脑"

### CPU 关键参数

| 参数 | 含义 | 示例 |
|------|------|------|
| 核心数 (Cores) | 物理核心数量 | 8核 |
| 线程数 (Threads) | 逻辑处理器数量 | 16线程 |
| 主频 (Base Clock) | 基础运行频率 | 3.6 GHz |
| 睿频 (Boost Clock) | 最大加速频率 | 5.0 GHz |
| TDP | 热设计功耗 | 65W / 125W |
| 制程 (Process) | 制造工艺 | 7nm / 5nm |
| 插槽类型 (Socket) | 与主板的接口 | LGA1700 / AM5 |

### CPU 常见故障

**CPU 本身很少损坏！** 报"CPU故障"前，先排查以下问题：

1. **过热关机** → 散热器安装不当、硅脂干了、风扇不转
2. **针脚弯了/断了** → 安装时没对准（AMD PGA 接口常见）
3. **主板针脚问题** → LGA 接口主板针脚歪了（比 CPU 更脆弱）
4. **电源供电不足** → CPU 8pin 供电没插或电源功率不够

### CPU 检测方法
```powershell
# 查看 CPU 详细信息
wmic cpu get name,numberofcores,numberoflogicalprocessors,maxclockspeed

# 查看 CPU 实时温度和频率（需要安装 HWiNFO 或 Core Temp）
# 推荐免费工具：HWiNFO64、CPU-Z、Core Temp
```

### CPU 温度参考范围

| 状态 | Intel | AMD |
|------|-------|-----|
| 待机 (Idle) | 30-40°C | 35-45°C |
| 普通负载 | 50-65°C | 50-70°C |
| 满载 (100%) | 70-85°C | 75-90°C |
| 过热降频阈值 | ~100°C | ~95°C |
| 危险温度 | >105°C | >100°C |

## 3. 内存 (RAM) — 临时工作台

### 内存类型识别

| 类型 | 速度范围 | 电压 | 插槽特征 |
|------|----------|------|----------|
| DDR3 | 1333-2133 MHz | 1.5V | 240pin，缺口偏左 |
| DDR4 | 2133-3600 MHz | 1.2V | 288pin，缺口偏右 |
| DDR5 | 4800-7200 MHz | 1.1V | 288pin，缺口位置不同 |

**⚠️ DDR3/4/5 互不兼容！插槽缺口位置不同，强行插入会损坏！**

### 内存常见故障

```
故障现象                   可能原因
─────────────────────────────────────
开机无显示 + 蜂鸣器长响   内存接触不良/损坏
蓝屏(BSOD)随机出现        内存有坏块
电脑识别不到全部内存       插槽故障/兼容性问题
系统运行越来越慢后死机     内存泄漏(软件) / 内存不足
```

### 内存检测方法
```powershell
# 查看内存信息
wmic memorychip get capacity,speed,manufacturer,partnumber

# 查看已安装内存总容量
systeminfo | findstr "Total Physical Memory"
```

**推荐检测工具**：
- **MemTest86**（免费）：制作启动U盘，彻底检测内存坏块
- **Windows 内存诊断**（系统自带）：`mdsched.exe`

### 内存排查三步法

```
1. 橡皮擦轻轻擦拭金手指（金色触点）去除氧化层
2. 换个插槽试试（确认是内存问题还是插槽问题）
3. 一根一根单独测试（确认哪根内存有问题）
```

## 4. 硬盘 (Storage) — 数据仓库

### 硬盘类型对比

| 特性 | HDD (机械硬盘) | SATA SSD | NVMe SSD (M.2) |
|------|---------------|----------|-----------------|
| 速度 | 80-160 MB/s | 500-550 MB/s | 3000-7000 MB/s |
| 价格/GB | ~¥0.3 | ~¥0.6 | ~¥1.0 |
| 寿命(写入量) | 无明确限制 | 150-600 TBW | 300-1200 TBW |
| 噪音 | 有(马达声) | 无 | 无 |
| 抗震 | 差 | 好 | 好 |
| 适合用途 | 大容量存储 | 系统盘/游戏 | 高性能需求 |

### 硬盘健康检测

```powershell
# 查看硬盘 S.M.A.R.T. 状态
wmic diskdrive get status,model,size

# 使用 chkdsk 检查文件系统错误
chkdsk C: /f /r

# 详细 S.M.A.R.T. 信息（推荐使用 CrystalDiskInfo - 免费）
```

### S.M.A.R.T. 关键指标

| 参数 | 含义 | 危险信号 |
|------|------|----------|
| Reallocated Sectors Count (05) | 重映射扇区数 | >0 说明盘面开始老化 |
| Current Pending Sector (C5) | 待映射扇区 | >0 有数据可能丢失 |
| Uncorrectable Sector (C6) | 不可修复扇区 | >0 盘已不可靠 |
| Power-On Hours (09) | 通电时间 | HDD >30000 小时需关注 |
| Temperature (C2) | 温度 | 持续 >50°C 影响寿命 |

**关键原则**：只要 05/C5/C6 有非零值，立即备份数据并更换硬盘！

## 5. 电源 (PSU) — 最容易被忽视的故障源

### 电源规格

- **功率**：办公机 300-450W，游戏/工作站 550-850W，服务器 800W+
- **80 PLUS 认证**：白牌 → 铜牌 → 银牌 → 金牌 → 白金 → 钛金（转换效率递增）
- **模组化**：非模组 / 半模组 / 全模组（线缆可拆卸）

### 电源故障的典型表现

```
⚡ 完全无法开机 → 电源可能已损坏
⚡ 开机后随机断电/重启 → 电源功率不足或不稳定
⚡ 开机风扇转一下就停 → 电源保护电路触发（可能有短路）
⚡ 闻到焦糊味 → 电源内部元器件烧毁，立即断电！
⚡ 高负载下蓝屏 → 供电不稳导致 CPU/显卡工作异常
```

### 电源检测方法

1. **短接测试**（验证电源是否通电）：
   - 拔掉所有供电线
   - 用回形针短接 24pin 的绿色线(PS_ON)和任意黑色线(GND)
   - 插电 → 电源风扇转动说明基本通电正常
   - ⚠️ 这只是基础测试，不能确认输出是否稳定

2. **万用表测电压**：
   - 黄色(+12V) → 主要为 CPU/显卡供电
   - 红色(+5V) → 主板/硬盘电路
   - 橙色(+3.3V) → 主板芯片组/M.2 SSD

3. **替换法**：用确定正常的电源替换测试

## 6. 显卡 (GPU) — 图像处理核心

### 显卡类型
- **集成显卡**：在 CPU 内部（Intel UHD / AMD Radeon Graphics），够日常办公用
- **独立显卡**：PCIe 插槽上的独立硬件（NVIDIA / AMD），游戏/设计/AI 必需

### 显卡故障现象
- 屏幕花屏、条纹、色块 → 显存故障或 GPU 虚焊
- 驱动不断崩溃恢复 → 供电不足或过热
- 风扇狂转但无显示 → GPU 或显存损坏
- 玩游戏黑屏/死机 → 过热或供电不足

## 动手实验：认识你的电脑

```powershell
# 1. 生成完整的硬件报告
msinfo32 /report C:\Users\%USERNAME%\Desktop\system-report.txt

# 2. 查看所有硬件信息（一条命令搞定）
wmic cpu get name && wmic memorychip get capacity && wmic diskdrive get model,size && wmic baseboard get product

# 3. 查看设备管理器中是否有黄色感叹号（驱动问题）
devmgmt.msc
```

## 自测题

1. 电脑无法开机，首先应该检查哪两个部件？
2. NVMe SSD 和 SATA SSD 有什么区别？哪个更快？
3. S.M.A.R.T. 中哪个指标最重要，发现异常后应该做什么？
4. 内存 DDR4 和 DDR5 能混用吗？为什么？
5. CPU 温度过高通常是什么原因？如何排查？

<details>
<summary>点击查看答案</summary>

1. **电源和主板**：确认电源线插紧、电源开关打开（有些电源有独立开关）、24pin和CPU 8pin供电插紧
2. **NVMe SSD 走 PCIe 通道（M.2 接口），速度可达 7000MB/s；SATA SSD 走 SATA 通道，上限 550MB/s。NVMe 快 10 倍以上**
3. **重映射扇区计数 (05) 和待映射扇区 (C5)**。一旦有非零值 → 立即备份数据 → 更换硬盘 → 不要等
4. **不能**。DDR4 和 DDR5 物理插槽缺口位置不同，电气特性不同，强行插入会损坏内存或主板
5. **散热器安装不当（最常见）、硅脂干了/没涂好、散热风扇不转、机箱风道堵塞、环境温度过高。排查顺序：检查风扇→重新涂硅脂→重新安装散热器→检查机箱风道**
</details>
