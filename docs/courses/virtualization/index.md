# 虚拟化技术课程

虚拟化是现代数据中心的基础。一台物理服务器可以跑几十台虚拟机，节省成本、提高利用率。

3. **[VMware vSphere入门](./03-vmware)** — ESXi安装、vCenter、vMotion
4. **[KVM与云化虚拟化](./04-kvm-cloud)** — Linux原生虚拟化、模板、自动化
