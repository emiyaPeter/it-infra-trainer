# 🔴 红队专项：渗透测试与攻击模拟

红队模拟攻击者视角，通过渗透测试发现系统的薄弱点。**在国内进行任何渗透测试，必须获得书面授权！**

## 红队学习路线

```
信息收集 → 漏洞扫描 → 漏洞利用 → 权限提升 → 横向移动 → 持久化 → 痕迹清理
```

## 核心技能

### 1. 信息收集 (Reconnaissance)

```bash
# 被动信息收集（不直接接触目标）
whois target.com           # 域名注册信息
dig target.com ANY         # DNS记录全收集
theHarvester -d target.com # 邮箱/子域名收集
shodan search 'org:target' # 设备搜索引擎

# 主动信息收集
nmap -sV -sC target.com    # 端口扫描+服务版本检测
nmap -p- target.com        # 全端口扫描
gobuster dir -u target.com -w wordlist.txt  # 目录爆破
```

### 3. 常见漏洞类型 (OWASP Top 10)

| 排名 | 漏洞 | 一句话解释 |
|------|------|-----------|
| A01 | 访问控制失效 | 普通用户访问了管理员页面 |
| A02 | 加密失败 | 敏感数据没加密或用了弱加密 |
| A03 | 注入 (SQL/OS/LDAP) | 用户输入被当作代码执行了 |
| A04 | 不安全设计 | 架构层面就有安全问题 |
| A05 | 安全配置错误 | 默认密码没改、目录列表开着 |
| A06 | 使用含漏洞的组件 | Log4j 就是个惨痛的例子 |
| A07 | 认证失效 | 弱密码策略、没有MFA |
| A08 | 软件和数据完整性失效 | CI/CD 流水线被污染 |
| A09 | 日志和监控失效 | 被入侵了半年都没发现 |
| A10 | SSRF (服务端请求伪造) | 服务器被利用访问内部服务 |

### 4. 渗透测试方法论

```
PTES (Penetration Testing Execution Standard) 标准流程：

1. 前期交互 — 确定范围、规则、授权
2. 情报收集 — OSINT、被动/主动扫描
3. 威胁建模 — 识别最有价值的攻击路径
4. 漏洞分析 — 确认和评估发现的漏洞
5. 漏洞利用 — 获得初始访问权限
6. 后渗透 — 提权、横向移动、数据获取
7. 报告撰写 — 发现的漏洞、复现步骤、修复建议
```
