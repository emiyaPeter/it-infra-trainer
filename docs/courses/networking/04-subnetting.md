# IP地址与子网划分

子网划分是 IT 基础设施工程师**最重要的基本功之一**。无论是配置网络、规划 VLAN、设置防火墙规则，还是在云上设计 VPC，子网计算无处不在。

## IP 地址基础

### IPv4 地址结构

IPv4 地址是 32 位的二进制数，通常写成 4 个十进制数（每 8 位一组）：

```
二进制: 11000000.10101000.00000001.00000001
十进制: 192     .168     .1       .1
```

- **网络位**：标识网络（类似街道名）
- **主机位**：标识网络中的主机（类似门牌号）
- **子网掩码**：区分网络位和主机位

### IP 地址分类（有类寻址）

| 类别 | 首字节 | 默认掩码 | 网络数 | 每网络主机数 | 典型用途 |
|------|--------|---------|--------|------------|---------|
| **A类** | 1-126 | 255.0.0.0 (/8) | 126 | 1677万 | 大型企业/ISP |
| **B类** | 128-191 | 255.255.0.0 (/16) | 16384 | 65534 | 中型企业 |
| **C类** | 192-223 | 255.255.255.0 (/24) | 209万 | 254 | 小型网络 |
| **D类** | 224-239 | — | — | — | 组播 |
| **E类** | 240-255 | — | — | — | 实验保留 |

**注意**：127.x.x.x 是回环地址（localhost = 127.0.0.1），不属于 A 类。

### 私有地址范围

这些地址在公网上不可路由，用于企业内部网络：

| 类别 | 私有地址范围 | CIDR |
|------|-------------|------|
| A类私有 | 10.0.0.0 - 10.255.255.255 | 10.0.0.0/8 |
| B类私有 | 172.16.0.0 - 172.31.255.255 | 172.16.0.0/12 |
| C类私有 | 192.168.0.0 - 192.168.255.255 | 192.168.0.0/16 |

**你的家庭路由器**大概率在用 `192.168.x.0/24`。

## CIDR 表示法

`/24`、`/26` 这些是什么意思？

- `/24` = 子网掩码有 24 个连续的 `1` = `255.255.255.0`
- `/26` = 子网掩码有 26 个连续的 `1` = `255.255.255.192`

```
/24: 11111111.11111111.11111111.00000000 = 255.255.255.0
/26: 11111111.11111111.11111111.11000000 = 255.255.255.192
/28: 11111111.11111111.11111111.11110000 = 255.255.255.240
```

### 关键公式

对于 `/N` 的子网：
- **子网掩码**：前 N 位为 1，后 (32-N) 位为 0
- **可用主机数**：2^(32-N) - 2（减去网络地址和广播地址）
- **网络地址**：IP 地址 AND 子网掩码
- **广播地址**：网络地址 OR (子网掩码的反码)

## 子网划分实战

### 例题1：基本计算

**对于 `192.168.1.0/24`：**
- 网络地址：`192.168.1.0`（主机位全0）
- 第一个可用IP：`192.168.1.1`
- 最后一个可用IP：`192.168.1.254`
- 广播地址：`192.168.1.255`（主机位全1）
- 可用主机数：254

### 例题2：等分子网

**将 `192.168.1.0/24` 划分为 4 个等大的子网：**

需要借 2 位（2^2 = 4），新掩码 = /26

```
子网1: 192.168.1.0/26   (192.168.1.0  - 192.168.1.63)   可用: 62台
子网2: 192.168.1.64/26  (192.168.1.64 - 192.168.1.127)  可用: 62台
子网3: 192.168.1.128/26 (192.168.1.128 - 192.168.1.191) 可用: 62台
子网4: 192.168.1.192/26 (192.168.1.192 - 192.168.1.255) 可用: 62台
```

### 例题3：按主机数划分子网

**公司有3个部门，分别需要 100、50、25 台主机，给你 `192.168.1.0/24`，如何分配？**

从大到小分配（最佳实践）：

1. **部门A（100台）**：需要容纳 128 个地址（100+2），/25 → `192.168.1.0/25` (126可用) ✅
2. **部门B（50台）**：需要容纳 64 个地址（50+2），/26 → `192.168.1.128/26` (62可用) ✅
3. **部门C（25台）**：需要容纳 32 个地址（25+2），/27 → `192.168.1.192/27` (30可用) ✅

剩余：`192.168.1.224/27` (30个地址) 备用

### 例题4：超网（路由汇总）

**将以下4个网络汇总成一条路由：**
```
192.168.0.0/24
192.168.1.0/24
192.168.2.0/24
192.168.3.0/24
```

第三字节的二进制：
```
0 = 000000|00
1 = 000000|01
2 = 000000|10
3 = 000000|11
        ↑ 变化从这里开始
```

前 22 位相同 → 汇总为 `192.168.0.0/22`

## 自测题

1. `/27` 有几个可用主机地址？
2. `10.0.0.0/8` 大约有多少可用主机？
3. 把 `172.16.0.0/16` 分成 8 个等大子网，每个子网的 CIDR 是什么？

1. 32 - 2 = 30 个（2^5 - 2）
2. 2^24 - 2 = 16,777,214 个（约 1677 万个）
3. 需要借 3 位（2^3=8），新掩码 /19
