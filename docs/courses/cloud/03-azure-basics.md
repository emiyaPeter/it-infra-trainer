# Azure 基础

很多企业（尤其外企和政府）用Azure。中国区Azure由世纪互联运营，和全球版有差异。

## 1. Azure VM

和AWS EC2类似。选区域→选镜像→选规格→配网络→创建。Azure门户操作比AWS更直观。

## 2. Azure AD (Entra ID)

Azure Active Directory是企业身份管理核心。和Windows AD不同——它是云原生的。支持SSO/MFA/条件访问。

## 3. 中国区差异

- 网站: portal.azure.cn（不是portal.azure.com）
- 虚拟机规格和全球版不同
- 部分服务在中国区未上线
- 数据不出境，合规
