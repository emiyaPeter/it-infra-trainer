# AI 辅助编程课程

AI 编程工具已经是工程师的"第二双手"——但会用和用好在相差巨大。同样的工具，有人用它十分钟搭出可运行的系统，有人被它带进幻觉 API 和烂泥潭。本课程教你**用工程化的方式驾驭 AI 编程**。

## 这门课适合谁？

- 学完前面阶段、想把 AI 融入日常学习和开发的准工程师
- 已经在用 AI 写代码，但经常被"带偏"、返工比手写还慢的人
- 想知道哪些活该交给 AI、哪些必须自己把关的人

## 课程目录

1. **[AI 编程基础与工具版图](./01-ai-coding-basics)** — LLM 工作原理浅析（token/上下文/幻觉）、工具全景、能与不能
2. **[提示词工程实战](./02-prompt-engineering)** — 结构化提示、迭代对话、计划先行、约束边界
3. **[AI 终端代理工作流](./03-agent-workflow)** — Claude Code 类命令行代理的正确用法：探索→计划→执行→验证
4. **[带着 AI 做完整项目](./04-ai-project-practice)** — 需求到交付全流程实战与踩坑清单
5. **[安全、质量与验证](./05-ai-safety-quality)** — 密钥保护、代码审查清单、测试护栏、依赖安全

## 学习建议

- 本课程**不依赖特定工具**：原理和方法论适用于任何 AI 编程助手（Claude Code、Cursor、Copilot、通义灵码、文心快码等）
- 每章的概念都配了"反面案例"——踩坑记忆比成功记忆深刻得多
- 学完第 4 章请真的动手做一个小项目；学完第 5 章回头检查你现在的用法有几个红线
