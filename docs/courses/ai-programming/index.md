# AI 辅助编程课程

从"会用 AI 写代码"到"能用 AI 独立交付项目并通过求职面试"，这是本课程的完整闭环。前五章练内功，后四章打求职之战。

## 课程结构（三篇）

### 📘 方法基础篇（01-05）

先建立对 AI 的准确认知与正确姿势——地基不牢，后面全是空中楼阁。

1. **[AI 编程基础与工具版图](./01-ai-coding-basics)** — LLM 工作原理浅析（token/上下文/幻觉）、工具全景、能与不能
2. **[提示词工程实战](./02-prompt-engineering)** — 结构化提示四要素、迭代对话、计划先行、约束边界
3. **[AI 终端代理工作流](./03-agent-workflow)** — 探索→计划→执行→验证四步循环、AGENTS.md、权限与回滚
4. **[带着 AI 做完整项目](./04-ai-project-practice)** — 书签管理器全流程实战与六大踩坑清单
5. **[安全、质量与验证](./05-ai-safety-quality)** — 密钥红线、安全五问、四层测试护栏、依赖安全

### 🛠 独立交付篇（06-07）

把方法论变成**你自己的、能拿得出手的项目**。

6. **[项目选题与定义](./06-project-definition)** — 面向求职的选题三原则、五大项目原型、一页纸需求文档、MoSCoW 与非目标
7. **[交付打磨](./07-delivery-polish)** — 面试官视角审项目、README 模板、ADR 决策记录、六连问深挖防线

### 💼 求职实战篇（08-09）

让项目变成 offer。

8. **[简历与作品集](./08-resume-portfolio)** — 量化表达公式、AI 技能加分写法、GitHub 门面四查、一页纸项目档案
9. **[面试实战](./09-interview-prep)** — 面试形式盘点与策略、六大高频问题回答框架、90 秒项目陈述模板、反问环节

## 配套练习

- **测验一**（第 1-5 章）：`npm run cli -- quiz ai-programming`
- **测验二**（第 6-9 章）：`npm run cli -- quiz ai-job` —— 求职实战篇检验

## 学习建议

- 第 4、6、7 章是**实操章**：请真的动手，光读不练等于没学
- 后四章的每个模板（需求文档、README、ADR、一页纸档案）都直接复制去用——它们就是为"抄走"而写的
- 学完全程的自检标准：**你的项目能被陌生人 10 分钟跑起来，你能扛住 30 分钟深挖**
