# 第 0 章 · 零基础起步

这一章假设你**完全没写过代码**。学完它，你能顺畅使用一个 AI 对话工具，并看懂本课程后面所有章节的术语。有基础的同学可以快速跳过，但"专有名词小词典"建议扫一眼。

## 1. 你需要准备什么

- 一台电脑 + 浏览器 + 一个邮箱（手机也行，但学习建议用电脑）
- **不需要**任何编程基础
- 不需要花钱：主流工具都有免费额度，学完本课程足够

## 2. 选你的第一个 AI 工具

零基础从**网页对话式工具**起步（点开网页就能用，零安装）：

| 工具 | 获取方式 | 特点 |
|------|----------|------|
| DeepSeek | deepseek.com，手机号注册 | 国内直连，免费，代码能力强 |
| Kimi | kimi.moonshot.cn | 国内直连，长文档处理友好 |
| 通义千问 | tongyi.aliyun.com | 阿里出品，集成在浏览器/办公套件 |
| 豆包 | doubao.com | 字节出品，界面最"聊天感" |
| ChatGPT / Claude / Gemini | 官网注册 | 国际主流；访问门槛自行确认 |

::: tip 选哪个？
**随便选一个开始，不要纠结**。对话式 AI 的核心用法（提问-反馈-验证）在所有工具上通用——方法论比工具重要一百倍，这正是本课程的主线。等你学到第 3 章（终端代理），再考虑进阶工具。
:::

## 3. 完成你的第一次对话（照着做）

打开你选的工具，把下面三段依次发给它（就当加了个很博学的朋友的微信）：

```text
第一句（破冰，验证它能听懂人话）：
你好！我完全不懂编程，请把我当成聪明的高中生，
用打比方的方式给我讲讲"什么是编程"。

第二句（提出你的真实需求）：
我在学 IT，今天遇到了一个词叫"IP地址"，
解释它是什么，并举一个生活里的类比。

第三句（练习"提要求"——这是第 2 章的核心技能预演）：
重新解释一次，要求：不超过 5 句话，其中一个类比
必须和"快递收货地址"有关。
```

做完这三句，你已经用到了本课程三个概念：**设定角色**（把我当高中生）、**提供背景**（我在学 IT）、**施加约束**（5 句话+指定类比）。提示词工程没有魔法，就是把这三件事说清楚。

## 4. 起步三条红线（比学任何技巧都重要）

1. **不粘贴隐私**：密码、身份证号、银行卡、家庭住址——任何 AI 对话里都不出现
2. **交叉验证事实**：AI 说"某个软件这样配置"——学习阶段多问一句"去哪里能核实"，养成查官方文档的习惯（第 1 章讲的幻觉，到时候你会遇上的）
3. **别把 AI 当唯一老师**：AI 给你的"知识"是起点不是终点——配合本课程的结构化章节 + 动手练习，才能真的学会

## 5. 专有名词小词典

本课程（和任何技术文档）的高频词，全部一句话人话版：

| 术语 | 人话解释 |
|------|----------|
| **token** | AI 处理文字的"积木块"，约半个到一个汉字；聊天按它计量 |
| **上下文窗口** | AI 一次能"看见"的对话总长度；聊太长它就忘了开头 |
| **幻觉** | AI 对不知道的事一本正经地编（会编出不存在的函数！） |
| **提示词 (Prompt)** | 你发给 AI 的那段话；写得好坏直接决定回答质量 |
| **Agent / 代理** | 不只会聊天、还能动手（开文件、跑命令）的 AI |
| **终端 / 命令行 / CLI** | 用打字而不是鼠标操作电脑的黑窗口 |
| **API** | 程序之间互相调用的"服务窗口"，如"查天气"接口 |
| **git** | 代码的"时间机器"，每一步都能存档、能回退 |
| **commit / 提交** | 用 git 存一个存档点，附一句"这次改了啥" |
| **仓库 (repo)** | 一个项目的全部文件 + 全部历史 |
| **GitHub** | 存放仓库的"网盘+社交平台"，求职必备门面 |
| **README** | 项目的自我介绍文件，打开项目第一眼看它 |
| **npm** | Node.js 的"应用商店"，装第三方代码包用 |
| **依赖** | 你的项目用到的别人写的代码包 |
| **Node.js** | 让 JavaScript 能在电脑上直接运行的引擎 |
| **MVP** | 最小可用版本——功能最少但能完整跑通的第一版 |
| **MoSCoW** | 需求分四档：必须有/应该有/可以有/不做（Must/Should/Could/Won't） |
| **ADR** | 架构决策记录——"为什么当时选 A 不选 B"的便签 |
| **STAR** | 讲经历的四步结构：背景-任务-行动-结果 |

## 6. 三周入门路径

| 周 | 目标 | 每日动作（30-60 分钟） |
|----|------|------------------------|
| 第 1 周 | 用好对话式 AI | 学本课程 1-2 章；每天把不懂的概念发给 AI："用打比方的方式讲 XX，我完全零基础" |
| 第 2 周 | 补齐动手地基 | 装好 Node.js（第 4 章预备课有一步一命令）；学第 3 章前先过它的"终端 5 分钟速成" |
| 第 3 周 | 做出第一个东西 | 跟着第 4 章把书签管理器做出来——做不出来就把自己卡住的地方发给 AI 问 |

**判断你"入门了"的标准**：你能不慌不忙地对 AI 说"不对，我要的是 XXX，改成 YYY"——即从"被 AI 牵着走"变成"你牵着 AI 走"。

## 常见误区（小白专属）

1. **第一个月就付费买高级工具** —— 方法论没学会前，付费只是买安慰；免费额度够用到第 4 章
2. **收藏了 20 个工具教程** —— 工具焦虑是最没必要的焦虑；选一个，用满三周
3. **看不懂的词直接跳过** —— 回来查第 5 节的词典；卡住你的往往不是概念，是一个词
4. **用 AI 生成学习笔记然后收藏吃灰** —— AI 帮你整理的东西要"过你的手"（改写一遍、讲给别人听）才算学会

## 小结

- 选一个免费对话工具立刻开始；第一次对话=角色+背景+约束
- 三条红线：不贴隐私、验证事实、不当唯一老师
- 词典在手，三周路径在墙上；入门标志是"你牵着 AI 走"

## 练习

1. 完成第 3 节的三句式第一次对话，截图存档（这是你 AI 之旅的第 1 天）
2. 让 AI "用打比方解释这五个词：token、上下文、幻觉、API、git"，对照词典校对它的讲法
3. 把三周路径写进你的日历，第 21 天回来验收
