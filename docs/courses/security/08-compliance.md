# 合规与标准

在中国做 IT，绕不开等级保护（等保）。本节从运维视角讲你实际要做什么。

## 1. 等保 2.0 五级

| 等级 | 对象 | 评审 |
|------|------|------|
| 一级 | 不危害社会的系统 | 自主保护 |
| 二级 | 一般网络（大多数企业） | 指导保护 → 公安备案 |
| 三级 | 重要系统（政府/金融） | 监督保护 → 每年测评 |
| 四级 | 特别重要系统 | 强制保护 |
| 五级 | 国家安全级 | 专门保护 |

## 2. 等保二级（最常见）运维检查清单

| 类别 | 要求 | 操作 |
|------|------|------|
| 物理安全 | 机房门禁 | 确保服务器物理访问受控 |
| 网络安全 | 防火墙/访问控制 | 部署防火墙、划分 VLAN |
| 主机安全 | 最小安装/最小权限 | 关闭无用服务、审计账号 |
| 应用安全 | 身份认证/访问控制 | 实施 MFA、RBAC |
| 数据安全 | 备份/加密 | 定期备份、传输加密 |
| 日志审计 | 操作留痕 | auditd、syslog 集中收集 |

## 3. 等保检查必备命令

```bash
systemctl list-units --state=failed  # 检查服务异常
iptables -L -n                       # 防火墙规则
awk -F: '$3==0{print $1}' /etc/passwd  # UID 0 账户
last -20                             # 登录审计
find / -perm -4000 2>/dev/null       # SUID 文件审查
```

## 4. 自测

<details>
<summary>1. 公司要过等保二级，运维要提前准备什么？</summary>
1. 整理所有服务器的资产清单和拓扑图
2. 确保防火墙规则、账户权限符合最小化原则
3. 开启并保存至少 6 个月的日志（auth、syslog、auditd）
4. 确保有定期备份和恢复测试记录
5. 漏洞扫描和修复记录
</details>

<details>
<summary>2. ISO 27001 和等保有什么区别？</summary>
ISO 27001 是国际信息安全管理体系标准（适用于全球业务），等保是中国法律要求的网络安全等级保护制度（在中国运营必须遵守）。两者可以互补：ISO 27001 侧重管理流程，等保侧重技术控制点。
</details>
