# 安全基础课程

> 🔒 你搭建的系统如果被攻破，是你的责任。

## 课程目录

### 基础篇：安全思维（第1-4章）

1. **[安全基础概念](./01-security-concepts)** — CIA三元组、纵深防御、最小权限、零信任模型
2. **[网络安全基础](./02-network-security)** — nftables防火墙、DMZ架构、Fail2ban、网络分段
3. **[系统安全加固](./03-system-hardening)** — SSH加固、CIS Benchmark、auditd、AIDE
4. **[身份与访问管理](./04-iam)** — RBAC、MFA、SSO、PAM认证流程

### 进阶篇：安全运维（第5-8章）

5. **[密码学基础](./05-cryptography)** — 对称/非对称加密、哈希、PKI、OpenSSL/TLS证书
6. **[安全监控与应急响应](./06-soc-ir)** — 日志分析、入侵检测、六步应急响应法
7. **[渗透测试基础](./07-pentest-basics)** — 侦察扫描、Web漏洞、以攻促防
8. **[合规与标准](./08-compliance)** — 等保2.0、ISO 27001、网络安全法
