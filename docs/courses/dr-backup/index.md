# 灾备与高可用课程

系统早晚会坏：磁盘会挂、机房会断电、人会误删。灾备（DR）与高可用（HA）是运维的"最后一道防线"——出事时，你的水平取决于**事前**做对了多少。

## 为什么这是必修课？

- 🔥 一次没备份的误删，可能比十次故障更致命
- 💼 招聘 JD 高频词："高可用架构""容灾方案""3-2-1 备份"
- 🧠 它把前面所学（Linux、网络、虚拟化、监控）串成完整闭环

## 课程目录

1. **[备份策略与实战](./01-backup-strategy)** — RPO/RTO、3-2-1 原则、全量/增量/差异、备份验证
2. **[RAID 与单机冗余](./02-raid-ha)** — RAID 级别选型、热备盘、电源/内存冗余
3. **[负载均衡与故障转移](./03-lb-failover)** — L4/L7 负载均衡、反向代理、VRRP 双机热备
4. **[灾备规划与演练](./04-dr-plan)** — 冷/热/双活、演练流程、恢复手册

## 实验环境

全部可在现有 WSL2 + VirtualBox 环境完成：

- 备份实验：WSL2（rsync / tar / 定时任务）
- 负载均衡实验：两台 Linux VM + Nginx / Keepalived

## 学习建议

- 每章问自己一个问题："如果**现在**这台机器没了，我能恢复到什么程度？"
- 学完回到 [阶段10 路线图](/roadmap/phase-10-dr) 自查，然后开始规划你自己的"终期项目"
