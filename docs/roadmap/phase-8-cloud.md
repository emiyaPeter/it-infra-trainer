# 阶段8：云计算基础

> 🎯 **目标**：理解云服务模型，能使用主流云平台的核心服务  
> ⏱ **建议时长**：3 个月  
> 📊 **难度**：⭐⭐⭐ 中级  

## 学习内容

- 云计算概念：IaaS/PaaS/SaaS、Region/AZ、CAPEX vs OPEX
- **AWS 核心**：EC2、S3、VPC、IAM、RDS、ELB、Auto Scaling
- **Azure 基础**：VM、Blob Storage、VNet、Azure AD
- 成本管理：定价模型、标签策略、预留实例

## 实验环境

- AWS Free Tier / Azure Free Account（注册免费，注意控制费用）
