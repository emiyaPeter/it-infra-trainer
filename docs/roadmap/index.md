## 学习建议

1. **循序渐进** — 必须按阶段顺序学习，每个阶段建立在前一阶段基础之上
2. **动手优先** — 每学完一个概念，立即在终端中动手验证。不要只看不练
3. **遇到问题先自己排查** — 故障排查是IT工程师最核心的能力
4. **做好笔记** — 用 Markdown 记录自己的理解和遇到的坑
5. **搭建实验环境** — 虚拟机和容器是你的沙盒，大胆尝试不要怕搞坏
6. **坚持每天** — 每天1-2小时比周末突击一整天效果好得多
