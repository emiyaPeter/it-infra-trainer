# 阶段6：自动化运维 (IaC)

> 🎯 **目标**：掌握基础设施即代码，能自动化管理服务器配置和云资源  
> ⏱ **建议时长**：4 个月（每天 1-2 小时）  
> 📊 **难度**：⭐⭐⭐ 中级  

## 学习内容

- **Ansible**：Inventory、Playbook、Roles、Variables、Templates、Ansible Vault
- **Terraform**：HCL 语法、Provider、State、Module、Plan/Apply 工作流
- **CI/CD 概念**：GitLab CI / GitHub Actions 流水线设计
- **Git 高级用法**：分支策略、Code Review、GitOps 概念

## 实验环境

- Docker 容器作为 Ansible 管理目标
- Terraform 使用本地 Docker Provider 练习
