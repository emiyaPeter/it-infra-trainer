# 阶段10：灾备与高可用

> 🎯 **目标**：能设计备份策略和高可用架构，制定灾备计划  
> ⏱ **建议时长**：2 个月  
> 📊 **难度**：⭐⭐⭐⭐ 进阶  

## 学习内容

- 备份策略：3-2-1 规则、全量/增量/差异备份、RTO/RPO
- 负载均衡：L4 vs L7、HAProxy/Nginx 配置
- 高可用：Active-Passive/Active-Active、集群与仲裁
- 灾备规划：DR 文档编写、演练流程

## 里程碑

设计一份 3 层应用的完整 DR 方案文档，并在 Docker 环境中验证关键步骤。
