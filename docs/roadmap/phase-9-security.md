# 阶段9：安全基础

> 🎯 **目标**：理解 IT 安全核心概念，能实施基础设施安全加固  
> ⏱ **建议时长**：2 个月  
> 📊 **难度**：⭐⭐⭐⭐ 进阶  

## 学习内容

- 安全基础概念：CIA 三元组、纵深防御、最小权限原则
- 网络安全：iptables/nftables 防火墙、IDS/IPS 概念、VPN
- IAM：RBAC、MFA、OAuth/OIDC 概念
- PKI 与证书：SSL/TLS、证书链、Let's Encrypt
- 安全合规：ISO 27001、SOC2、GDPR 基础认知
