# 阶段7：监控与日志

> 🎯 **目标**：能搭建完整的监控和日志系统，让基础设施可观测  
> ⏱ **建议时长**：2 个月  
> 📊 **难度**：⭐⭐⭐ 中级  

## 学习内容

- **Prometheus**：Metrics 收集、PromQL 查询、Exporters (node_exporter)
- **Grafana**：仪表盘设计、数据源配置、告警规则
- **ELK Stack**：Elasticsearch + Logstash + Kibana（日志收集分析）
- **四大黄金信号**：延迟、流量、错误、饱和度

## 实验环境

Docker Compose 一键启动：Prometheus + Grafana + Node Exporter + ELK

## 里程碑

Grafana 仪表盘展示 3 台容器的 CPU/内存/磁盘/网络指标。
