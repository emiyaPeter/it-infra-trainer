# 📝 随堂测验

做完题不用自己"宣布学会"：**测验达标（≥80 分）自动点亮对应模块的全部章节进度**，错过的题自动进错题本，配好 AI 密钥还能要一份针对你错误答案的精讲。

<QuizWidget />

## 使用说明

- **判分规则**：选择题由本地规则判分（准确、离线）；填空题先与标准答案比对（含可接受写法），对不上且配置了 AI 时交给 AI 判分——AI 判你错时还会自动再跑一轮**对抗审计**，专门防止"把对的判错"。
- **AI 是可选增强**：不配密钥一切功能照常（填空题按标准答案严格比对）。密钥只保存在你本机浏览器，本站代码与仓库零密钥（BYOK 模式，详见[架构决策记录](/adr/)）。
- **双轨完成机制**：测验达标自动点亮模块章节；阅读时手动点「标记已完成」依然有效——两者是同一份进度，互不冲突。
- **错题本**：按题库分组，重做答对自动移出；支持"只重做本组错题"逐组攻克。
