# 证书考试路线图

IT 证书是求职的敲门砖。本路线图帮你规划：**学完哪些内容可以考哪些证**。

```
                        IT基础设施 + 安全 证书路径

入门级 (0-6个月)          进阶级 (1-2年)              高级 (3年+)
──────────────────────────────────────────────────────────────
CompTIA Network+ ─────→ CompTIA Security+ ─────→ CISSP (需5年经验)
    │                         │
    ├── CCNA ──────────→ CCNP Security          OSCP (渗透测试)
    │                         │
    ├── RHCSA ─────────→ RHCE (Ansible)         CKA (K8s管理员)
    │                         │
    └── 软考-网络工程师 ──→ 软考-信息安全工程师     AWS SA Pro

                            HCIA/HCIP Security
                            (华为认证-安全)
                            等保测评师
```

## 分阶段证书规划

### 阶段1-2 完成时可考 (学习 3-8 个月后)

**CompTIA Network+** — 网络基础
- 考试代码：N10-009
- 题型：90 道选择题 + 实操题
- 通过线：720/900
- 本课程覆盖度：✅ **阶段1全部覆盖**
- 建议：学完阶段1后直接报名

**软考-网络工程师（中级）** — 国内职称
- 考试时间：每年5月、11月
- 题型：上午 (75道选择) + 下午 (5道案例分析)
- 通过线：单科 ≥45分（满分75）
- 本课程覆盖度：✅ 阶段1+2 覆盖约 80%

### 阶段2-4 完成时可考 (学习 8-12 个月后)

**CCNA (Cisco Certified Network Associate)**
- 考试代码：200-301
- 题型：选择题 + 实验模拟题
- 通过线：~825/1000
- 费用：~$300 + 实验设备 (~$200 二手)
- 建议：学完阶段1+2 后用 Packet Tracer（免费）练习
- 本课程覆盖度：✅ 阶段1+2+4 覆盖约 85%

**RHCSA (Red Hat Certified System Administrator)**
- 考试代码：EX200
- 题型：**纯实操**！没有选择题，在真实 Linux 上完成配置任务
- 时间：3小时
- 费用：~$400
- 建议：学完阶段2后，搭建 CentOS/RHEL VM 大量练习
- 本课程覆盖度：✅ 阶段2 覆盖约 75%，需要额外练习 RHEL 特有工具

### 阶段2-5 完成时可考 (学习 8-16 个月后)

**CompTIA Security+** — 安全入门首选 ⭐
- 考试代码：SY0-701
- 题型：90 道选择题 + 实操题
- 通过线：750/900
- 本课程覆盖度：✅ 阶段1+2+9 覆盖约 85%
- **建议作为第一张安全证书**

**软考-信息安全工程师（中级）**
- 本课程覆盖度：阶段1+2+9 覆盖约 75%

### 阶段5-8 完成时可考 (学习 1.5-3 年后)

**CKA (Certified Kubernetes Administrator)**
- 题型：纯实操！在 K8s 集群上完成命令行任务
- 本课程覆盖度：阶段5 覆盖约 70%

**AWS Solutions Architect Associate**
- 本课程覆盖度：阶段8 覆盖约 65%，需额外学习

**CISP** — 国内安全领域最有分量的证书
- 报考条件：本科+1年安全经验 / 专科+2年
- 培训：必须参加官方授权培训（约 5 天）
- 本课程覆盖度：阶段1+2+9+安全课程 覆盖约 70%

### 学完全部后可挑战 (3年+)

- **CISSP** (需要 5 年安全经验，可用证书抵 1 年) — 安全领域的"天花板"
- **OSCP** — 渗透测试实战认证，24小时攻防考试

## 备考策略

### 零基础 → 第一张证书（6个月内）

```
最佳路径: 学阶段1 → 考 CompTIA Network+
备选路径: 学阶段1+2 → 考 软考-网络工程师
```

### 转安全方向（1年内）

```
最优路径: Network+ → Security+ → CISP
快速路径: 学完全部课程 → 软考-信息安全工程师
```
