一、快速开始
────────────────────────────────────────────────────────────

  cd it-infra-trainer
  npm install
  npm run init-db
  npm run dev              ← 一键启动，服务就绪后自动打开浏览器

  浏览器访问 http://localhost:5173（通常已自动打开）
  右上角注册账户（姓名 + 手机号 + 密码）
  点击 "🚀 一个月速成" 开始学习！

二、学习方式
────────────────────────────────────────────────────────────

  方式一: Web 文档网站（推荐新手）
    npm run dev         启动后自动打开 http://localhost:5173
    功能: 课程阅读 | 注册登录 | 完成标记 | 在线测验+错题本
          | 仪表盘 | 番茄钟 | 学习数据导出/导入
    （无需任何后端服务，账户数据存于浏览器本地，断网可用）

  方式二: CLI 命令行
    npm run cli -- quiz networking    做测验
    npm run cli -- lab --list         做实验
    npm run cli -- progress           看进度

三、CLI 命令速查
────────────────────────────────────────────────────────────

  学习:
    npm run cli -- roadmap           学习路线图
    npm run cli -- roadmap -p 2      阶段2详情
    npm run cli -- start "Linux"     开始学习会话
    npm run cli -- search "关键词"    搜索课程内容

  测验与实验:
    npm run cli -- quiz              列出测验
    npm run cli -- quiz networking   网络测验
    npm run cli -- lab --list        列出实验
    npm run cli -- lab linux-file-permissions  做实验
    npm run cli -- homework --list   列出作业

  进度与统计:
    npm run cli -- progress          学习进度
    npm run cli -- stats             学习统计

  工具:
    npm run cli -- env-check         检查环境配置
    npm run cli -- export-progress   导出当前用户学习记录 JSON
    npm run cli -- ask "问题"        AI 答疑（带课程出处）

  数据维护:
    npm run backup                   手动备份数据库（每次启动也会自动备份，
                                      存 data/backups/，保留最近 7 份）
    npm test                         冒烟自检（语法+CLI+构建，改代码后必跑）
    首页仪表盘 → 导出/导入备份       浏览器学习数据迁移（换浏览器/换电脑）

八、AI 答疑（可选功能）
────────────────────────────────────────────────────────────

  首次配置（约 1 分钟）:
    双击「设置AI密钥.bat」或运行 npm run set-key
    → 选服务商（DeepSeek 默认 / Kimi / 智谱 / 自定义）
    → 粘贴 API 密钥（输入时隐藏）→ 自动存入本地 .env

  使用:
    npm run cli -- ask "什么是子网掩码"
    npm run cli -- ask "systemctl 和 service 命令的区别"

  说明:
    - 回答优先基于本站课程内容，并附出处章节，方便回读
    - 密钥只存本地 .env（已被 gitignore），永不入库、不上网页
    - 重复运行 set-key 可随时更换服务商或密钥
    - 注意：问题文本会发送给你所选的 AI 服务商

九、在线测验与错题本（Web 端，v2.5 起；v2.6 扩容）
────────────────────────────────────────────────────────────

  入口: 导航栏「📝 随堂测验」（线上站同路径 /quiz/）
        课程章节页右下角「📝 本章小测」按钮（该章有配套题目才显示）

  题库规模（v2.6 扩容，v2.8 全量审校）:
    - 19 套题库、184 道题，覆盖全部 17 个课程模块（每套 8 选择 + 1 填空
      或主观题）+ AI 求职专项；全部题目经双维度审校（正确性+效度，
      见 docs/question-audit.md），以后加题只需往 quizzes/ 放 JSON
      文件，网页自动上线，npm test 会校验格式与效度
    - 发现题目有误：错题本页有「报告题目问题」入口（GitHub Issue）

  做题:
    - 选题库 → 逐题作答（选择题点选项，填空题输入，问答/实操题写要点
      或命令）→ 每题即时反馈 → 交卷出分数与错题讲解
    - 未登录可做题但不保存；登录后成绩/错题按账户留存

  主观题 AI 判卷（v2.6，可选）:
    - 配好 AI 密钥后，问答题/实操题由 AI 按三档判分: 正确 1 分 /
      部分正确 0.5 分 / 未达要点 0 分；判 0 分会自动再跑一轮对抗审计
      防止错杀
    - 未配密钥: 题目照常可做，作答后看参考答案自评（不计入总分，
      客观题照常判分达标——"无密钥不惩罚"）
    - CLI 端遇到主观题会跳过并展示参考答案（AI 判卷仅 Web 端）

  达标点亮（双轨完成机制）:
    - 模块测验 ≥80 分 → 自动点亮该模块全部章节进度
    - 手动「标记已完成」仍然有效，两者同一份进度互不冲突

  错题本:
    - 做错的题自动留存（你的答案/正确答案/解析/错误次数）
    - 按题库分组查看，支持"只重做本组"，答对自动移出
    - 每题带「📖 回读本章」链接直达对应课程章节；可点「🤖 AI 精讲」

四、用户管理
────────────────────────────────────────────────────────────

  Web 端（推荐）:
    右上角按钮操作 → 注册 / 登录 / 切换账户（切换需验证密码）
    账户与进度存于浏览器 localStorage，换浏览器需重新注册

  🔑 恢复码（v2.7 新增，强烈建议保存）:
    - 注册成功后会显示一次恢复码——忘记密码时唯一找回方式
    - 丢失或没保存：登录后在首页仪表盘「🔑 恢复码」重新生成
      （旧码立即失效）
    - 忘记密码：登录弹窗 →「忘记密码？用恢复码重置 →」

  📤 数据备份（v2.7 增强）:
    - 备份现在包含：账户（密码+恢复码哈希）、学习进度、
      测验成绩、错题本
    - 超过 7 天未备份时仪表盘会显示提醒条
    - 「📋 学习报告」：新标签页生成可打印 PDF 的报告，
      各模块按 证据分级 呈现（测验达标验证 / 仅自报已读 /
      未开始）——给上级或自己看真实学习效果

  🎓 结业证书:
    测验达标的模块在仪表盘「📈 测验成绩」区有「🎓 证书」
    按钮，本地生成 PNG（标注为自学完成证明，非官方认证）

  🎯 模拟考试:
    测验页「🎯 模拟考」标签 → 从全部题库随机抽 10/20/30 道
    客观题，限时作答（考试中不显示对错），到时自动交卷，
    交卷后统一回顾+错题自动入本

  CLI 命令行:
    npm run cli -- user create <姓名> <手机号>
    npm run cli -- user switch <姓名>
    npm run cli -- user list
    npm run cli -- user current
    npm run cli -- user delete <姓名>

  注意: Web 账户（浏览器本地）与 CLI 账户（data/data.db 数据库）
        是两套独立数据，互不影响。CLI 的 set-password 命令属于
        旧版可选认证服务，日常无需使用。

六、常见操作场景
────────────────────────────────────────────────────────────

  场景1: 今天学了 Linux
    npm run cli -- start "Linux命令行"

  场景2: 测试网络知识
    npm run cli -- quiz networking

  场景3: 多人共用
