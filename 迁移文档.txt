一、项目概述
────────────────────────────────────────────────────────────
IT Infra Trainer 是一个离线优先的 IT 基础设施培训系统，包含：

  组件              技术                          端口
  ─────────────────────────────────────────────────────
  Web 文档网站       VitePress + Vue 3             5173
  认证 API 服务      Express + bcrypt（可选，      3456
                    默认不启动，仅排查历史数据用）
  CLI 命令行工具     commander + inquirer           —
  数据库             SQLite (better-sqlite3)        —

  v2.2 起网页端账户完全存于浏览器 localStorage，
  默认启动只需要 Web 文档网站一个进程。

二、快速迁移（新机器部署）
────────────────────────────────────────────────────────────

步骤 1: 拷贝项目
  复制整个 it-infra-trainer 文件夹到目标机器

步骤 2: 安装 Node.js
  下载安装: https://nodejs.org （LTS 版本，>=18）

步骤 3: 安装依赖
  cd it-infra-trainer
  npm install
  npm approve-scripts better-sqlite3
  npm approve-scripts esbuild

步骤 4: 初始化
  npm run init-db

步骤 5: 启动
  npm run dev          ← 一键启动，就绪后自动打开浏览器
  浏览器打开 http://localhost:5173

步骤 6 (可选): 迁移旧数据
  将旧项目的 data/ 文件夹复制到新项目根目录

三、数据文件说明
────────────────────────────────────────────────────────────

  data/
  ├── data.db               SQLite 数据库（CLI 用户、进度、测验记录）
  ├── active-user.json      当前活跃用户桥接文件（仅本地）
  └── users.json            用户列表导出（仅本地，可选生成）

  注意: v2.2 起用户数据不再复制到 docs/public/data（隐私保护）。
  config.json               项目配置文件（dataDir 路径）
  .env                      密钥文件（gitignored，不随项目分发）

四、版本变化 (v1 → v2.2)
────────────────────────────────────────────────────────────

  v2.2 变化:
    + 架构简化: npm run dev 不再启动认证服务（Web 端账户已内置
      于浏览器本地，离线可用，静态模式同样支持注册登录）
    + 启动体验: 服务就绪后才自动打开浏览器（消除旧版固定等 2 秒
      的竞态）；关闭窗口可靠回收子进程
    + 隐私保护: 用户数据（姓名/手机号）不再发布到 docs/public/data
    + 跨平台修复: 作业/实验的实操检查在 Windows 上自动通过 WSL
      执行（原先硬编码 /bin/bash 会全部失败）
    + 修复: 启动器检查的数据库文件名错误（it-trainer.db → data.db）
    + 安全: Web 端密码哈希升级为多轮迭代 v2 格式（旧账户登录时
      自动迁移，无感知）；仪表盘移除免密切换，统一走右上角验证密码
    + 移除: config.json 中失效的 $schema 引用

  v2.1 新增:
    + Web 注册/登录/切换（密码认证）
    + Express 认证 API 服务
    + npm run dev 一键启动
    + set-password CLI 命令
    + 一个月速成学习路线
    + 课程内容扩充至 30 章

  v2.0 新增:
    + 多用户管理
    + 数据目录改为 ./data/（项目内，便于移植）
    + .env 安全机制
    + 用户隔离（每用户独立进度）

六、常见问题
────────────────────────────────────────────────────────────

Q: 拷贝到新电脑后启动报错？
A: 1) 确认 Node.js >=18  2) npm install 重新安装依赖
   3) 如果 better-sqlite3 编译失败，安装 Visual Studio Build Tools

Q: Web 端看不到注册/登录按钮？
A: 任何启动方式（npm run dev / docs:dev / docs:static）都有
   注册登录功能，右上角操作。账户存于浏览器本地，无需后端。

Q: 老用户（CLI创建）无法Web登录？
A: CLI 用户与 Web 用户是两套独立数据。Web 端请直接注册账户；
   CLI 端继续用 user switch 切换。旧认证服务（npm run auth）
   仅用于排查 v2.1 时代的历史数据。

Q: 数据库如何备份？
A: 直接复制 data/data.db 文件即可
