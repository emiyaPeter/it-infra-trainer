一、项目概述
────────────────────────────────────────────────────────────
IT Infra Trainer 是一个离线优先的 IT 基础设施培训系统，包含：

  组件              技术                        端口
  ─────────────────────────────────────────────────────
  Web 文档网站       VitePress + Vue 3           5173
  认证 API 服务      Express + bcrypt             3456
  CLI 命令行工具     commander + inquirer         —
  数据库             SQLite (better-sqlite3)      —

二、快速迁移（新机器部署）
────────────────────────────────────────────────────────────

步骤 1: 拷贝项目
  复制整个 it-infra-trainer 文件夹到目标机器

步骤 2: 安装 Node.js
  下载安装: https://nodejs.org （LTS 版本，>=18）

步骤 3: 安装依赖
  cd it-infra-trainer
  npm install
  npm approve-scripts better-sqlite3
  npm approve-scripts esbuild

步骤 4: 初始化
  npm run init-db

步骤 5: 启动
  npm run dev          ← 一键启动（认证 + 网站）
  浏览器打开 http://localhost:5173

步骤 6 (可选): 迁移旧数据
  将旧项目的 data/ 文件夹复制到新项目根目录

三、数据文件说明
────────────────────────────────────────────────────────────

  data/
  ├── data.db               SQLite 数据库（用户、进度、测验记录）
  ├── active-user.json      当前活跃用户桥接文件
  └── users.json            用户列表（不含密码）

  docs/public/data/         Web 端静态数据副本
  config.json               项目配置文件（dataDir 路径）
  .env                      密钥文件（gitignored，不随项目分发）

六、常见问题
────────────────────────────────────────────────────────────

Q: 拷贝到新电脑后启动报错？
A: 1) 确认 Node.js >=18  2) npm install 重新安装依赖
   3) 如果 better-sqlite3 编译失败，安装 Visual Studio Build Tools

Q: Web 端看不到注册/登录按钮？
A: 必须用 npm run dev 启动（不是 npm run docs:dev）
   这会同时启动认证 API (3456) 和 Web (5173)

Q: 老用户（CLI创建）无法Web登录？
A: 运行 npm run cli -- user set-password <用户名> <密码>

Q: 数据库如何备份？
A: 直接复制 data/data.db 文件即可
